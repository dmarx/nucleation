# LIT-tmp1hbb9: Theory of Value: An Axiomatic Analysis of Economic Equilibrium

Gerard Debreu (1959), *Theory of Value: An Axiomatic Analysis of Economic
Equilibrium*, Cowles Foundation Monograph 17, New York: Wiley; fourth
printing, Yale University Press, 1971. URL: the Cowles Foundation's PDF.

## Key takeaways

Read for §4.6 and its notes only.

- **The question.** Can each indifference class be given a real number
  "in such a way that, if a class is preferred to another, the number of
  the first is greater than the number of the second?" "The answer to
  the existence question is: not necessarily so (see an example in note
  2)" (pp. 55–56).
- **Continuity assumption (a).** For every x′, the sets {x | x ≾ x′} and
  {x | x ≿ x′} are closed (p. 56).
- **Theorem (1).** "Let Xᵢ be a connected subset of Rˡ, completely
  preordered by ≾. Under assumption (a) there is on Xᵢ a continuous
  utility function" (p. 56). The proof builds an increasing map from a
  countable dense subset onto the rationals of an interval and extends
  it by suprema (pp. 56–59). Conversely, a continuous utility function
  implies (a).
- **The general form, and its credit.** Only the countable dense subset
  is used, so the theorem holds for "a connected, separable topological
  space". "In this form it is essentially a result of S. Eilenberg"
  (1941), and connectedness "has been removed for spaces satisfying the
  second axiom of countability in G. Debreu [3]" (the 1954 paper, p. 73).
- **The lexicographic counterexample.** "An example of a complete
  preordering which cannot be represented by a real-valued function is
  the lexicographic ordering of R²" (p. 72). The proof sets up a
  one-to-one correspondence between the reals and a countable set of
  disjoint intervals (p. 73).
- **Utility is ordinal.** Any increasing transform of a utility function
  is one too, so "a corresponding utility function is thus arbitrary to a
  large extent" (p. 56).
