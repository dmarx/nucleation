## A correction, and the owner's correction of it

In chat the assistant first said a predicate that pins a value exactly puts
a feature in the conserved part. In filing it reversed this, saying that
enforcing a pinned value "erases where the entry started" and is
contraction. The owner corrected the reversal: "no it doesn't. it's a pinned
value on what was previously a free dimension. it's adding an exact
descriptor on a dimension that was previously undescribed. there's no drift
here, it's downward closed." The assistant's error was to model the pin as
moving the entry, when a descriptor is one the entry already passes: adding
it excludes other versions and moves nothing, and the admissible sets only go
down with the entry in each. Only an imposition, a value the entry fails,
moves it. CLAIM-tmp8v75o part 5, TERM-tmp7m4at, CLAIM-tmpj4fzn and the note on
TERM-132 were revised before merging to say so. The run's pinned coordinate
had shown it: held at its own value, it read 0.700 throughout.

## Stabilization

The filing first deferred "stabilization", on the ground that the record
uses "stabilized" for attraction toward convention (CLAIM-068). The owner:
"I'm using 'stabilization' in the control theoretic sense, it isn't a narrow
term of art describing attraction specifically towards conventions, the
attraction toward a convention is a manifestation of a more general
'stabilization' process. I'm using stability to mean the damping of
perturbations and convergence to expectation." Filed as TERM-tmp0g123, with
contraction (THEORY-2043) as a sufficient condition and CLAIM-068's case as
one instance; CLAIM-tmpj4fzn now states the narrowing as stabilization.

## The check

    # pred.py: restatement as noise then projection onto the predicates' sets
    import numpy as np
    rng = np.random.default_rng(7)
    d, sig, n, M = 6, 0.05, 400, 2000
    def halfspaces(k):
        a = rng.normal(size=(k, d)); a /= np.linalg.norm(a, axis=1, keepdims=True)
        return a, rng.uniform(0.3, 1.0, k)          # a.x <= b, origin feasible
    def project(x, a, b, R=2.0, sweeps=50):         # cyclic projections onto halfspaces and a ball
        for _ in range(sweeps):
            for ai, bi in zip(a, b):
                v = x @ ai - bi; x = x - np.maximum(v, 0)[:, None] * ai
            r = np.linalg.norm(x, axis=1, keepdims=True); x = x * np.minimum(1, R / r)
        return x
    def viol(x, a, b, R=2.0):
        return max(np.max(x @ a.T - b, initial=-np.inf), np.max(np.linalg.norm(x, axis=1) - R))
    a_all, b_all = halfspaces(24)
    x0 = np.zeros((M, d))
    for k in (0, 4, 8, 16, 24):
        a, b = a_all[:k], b_all[:k]; x = x0.copy()
        for _ in range(n):
            x = project(x + sig * rng.normal(size=x.shape), a, b, sweeps=5)
        dr = np.linalg.norm(x - x0, axis=1)
        print(k, viol(x, a, b), dr.mean(), dr.max(), x.std(0).mean())
    for name, v in (("source value 0.7", 0.7), ("convention 0.0", 0.0)):
        x = np.full((M, d), 0.7)
        for _ in range(n):
            x = x + sig * rng.normal(size=x.shape); x[:, 0] = v
        print(name, x[:, 0].mean(), np.std(x[:, 1] - 0.7), sig * np.sqrt(n))
    a, b = a_all, b_all
    for lam in (0.1, 1, 10, 100, 1e4):
        x = x0.copy()
        for _ in range(n):
            y = x + sig * rng.normal(size=x.shape); x = (y + lam * project(y.copy(), a, b, sweeps=5)) / (1 + lam)
        print(lam, np.linalg.norm(x - project(x.copy(), a, b), axis=1).mean())
