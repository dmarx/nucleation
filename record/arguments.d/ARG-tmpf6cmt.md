# ARG-tmpf6cmt: The exit-driven drift toy shows that a practice can expand under an honest count of present users' complaints, through the exit it causes alone

## The inference

CASE-tmp34j9u is a model in which the claim's premises hold: an honest
complaint count, exit rising with the practice, and myopic choice. The
practice rises. So the claim's "can" holds.

## Critical questions

- **Is the case coherent?** Yes: a two-group birth–death model with a
  closed-form optimizer, run with python3 -I. The steady-state identities
  (N_d = a_d/(e0 + e1·x)) check against the run.
- **Does it separate the very things the conclusion says can come apart?**
  Yes. The control arm, identical except that its score ignores exit,
  keeps x fixed, so the drift is due to the composition change and not to
  the optimizer or the arrivals. And no element of the model acts on
  complaints, so expansion and counter-corrective action come apart.

## Verdict

Proposed. The existence holds in the model. Its reach to organizations is
the claim's hypothesis, not this argument's.
