# CLAIM-tmpb125k: That adding an intervention to a working set can make an organization's target less likely is not shown by the open evaluations coded for equal budgets at different places: none has a larger set doing worse than a smaller one, and the one nested comparison found went the other way

## What is disclaimed

The coding (CASE-tmpjfl6r) asked of each case whether an arm that is
another arm plus a further component does worse. Only one case has such
arms: Seva Mandir's camps with incentives against camps alone
(THEORY-tmp7jput), and the superset did better. The others have no
nested arms.

So the record does not hold, from these cases, that adding an
intervention can make an organization fail. Nor does it hold the
opposite: one nested comparison in which adding helped says nothing about
whether adding can hurt.

## What would change it

A documented organizational comparison of a set of interventions and a
superset of it, on one outcome, in which the superset does worse, with
the added component's place in the structure named.
