# THEORY-tmpaxysg: Wu and colleagues (2024) find that chat assistants with memory and long-context LLMs lose roughly 30% to 60% accuracy when the evidence for a question about the user is spread through a long interaction history rather than given alone, and that storing extracted facts or summaries instead of the original rounds loses information and lowers accuracy except on questions that combine several sessions.

## The account

Wu and colleagues (2024) find that chat assistants with memory and
long-context LLMs lose roughly 30% to 60% accuracy when the evidence for a
question about the user is spread through a long interaction history rather
than given alone, and that storing extracted facts or summaries instead of
the original rounds loses information and lowers accuracy except on questions
that combine several sessions.
