# LEAD-tmpdesma: Run audited governance against a contextual router, given the same audit delay and cost, after expertise reverses and in the arms where a router could lose

## What it would do

Run CASE-158 with the router matched on audit delay and cost, adding one
arm per failure QUESTION-271 lists: cycles, no common scale, capture,
bandit feedback, and continued training.

Where the record names it:

- CLAIM-467: "A run of CASE-158's design, with the router given the same
  audit delay and cost, in which audited governance has lower held-out error
  than the router under full-information, independent audits"
- CASE-158: "What would make it informative is one arm per failure of
  QUESTION-271"
- ARG-036: "Does it tell the hypothesis apart from its rivals? Not yet.
  This is the question that fails."

## What would count

Audited governance with lower held-out error than the matched router in
some arm defeats CLAIM-467 as stated and names a regime where governance
adds something. The router matching or beating it in every arm supports
CLAIM-467 and answers ARG-036's failed question against the line.
