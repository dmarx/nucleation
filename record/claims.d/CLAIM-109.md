# CLAIM-109: In translation the pragmatic frame does not merely select a description of meaning but participates in determining which meaning becomes actual

## The claim

A21: "**Translation can be understood as a context-dependent realization of
communicative potential, in which the pragmatic frame does not merely select a
description of meaning but can participate in determining which meaning becomes
actual in the interpretive interaction.**" Translations would be "different
interventions that actualize different possibilities latent in the original's
interpretive structure".

## Why it was replaced

Its argument is [ARG-002](../arguments.d/ARG-002.md), undercut by [CLAIM-041](CLAIM-041.md). A27: "Here I would actually moderate
something I said earlier." Its conclusion was not refuted; it was demoted to a
hypothesis ([CLAIM-009](CLAIM-009.md)). The actualization language does not appear in the
manuscript.
