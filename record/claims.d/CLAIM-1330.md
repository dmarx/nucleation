# CLAIM-1330: Webhosts, various ones, can meet the demands normally met by a publisher, once editorial judgement has gone to editors and journals as feeds over them

## The claim

The owner's words: "(Various) 'webhost'(s) as (satisfying the demands
normally met by a) 'publisher'."

The parentheses carry the claim: hosts in the plural, meeting the demands a
publisher meets, not being one. A12 reads it as the last layer of U4's
split: "authors create the research, editors curate it, journals organize
editorial views, and webhosts provide the services traditionally bundled
into a publisher." A13 calls the term "deliberately unglamorous. It
emphasizes that we're talking about providing a service, not exercising
authority over the scientific literature."

## What it does not say

Not that one web server is a publisher. A13: "throwing an HTML file on a
web server doesn't automatically make that server a credible scientific
publisher." The functions a host leaves to others are [CLAIM-1346](CLAIM-1346.md).
