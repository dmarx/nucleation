# QUESTION-tmphovmg: Against which reference set is an organization scored for a demand that was never in its specification, when neither the original specification nor its own current one names it?

## What makes it open

[CLAIM-361](../claims.d/CLAIM-361.md) (Active) fixes a reference set D₀ of the original demands, so a
demand excised from D₀ counts against the organization. The manuscript's
§9.8 arm introduces a harm that was never in D₀. Excising it scores zero
violations against D₀ and against the organization's own specification
while the harm runs for all 120 periods, and "Only the true demand set
ranks the two correctly". Applying [CLAIM-361](../claims.d/CLAIM-361.md) to a demand outside D₀ carries
it past its own case (the manuscript's join JC4), and a third reference
set is needed that is neither D₀ nor the organization's own.

Candidates: D₀ revised by a party independent of the organization
([QUESTION-482](QUESTION-482.md)'s condition of independence); the demands of those affected;
a procedure for admitting new demands, judged by its own standard. Each
moves the question to who holds the set and with what right, which is
[QUESTION-485](QUESTION-485.md)'s.

## What would count as an answer

A rule that names the third reference set, says who may revise it and
when, and keeps the scoring from being one the scored organization
controls ([CLAIM-727](../claims.d/CLAIM-727.md)'s limit on self-certification).
