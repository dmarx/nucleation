summary: >-
  Elhage et al. (2022),
  [ARXIV-2209.10652](https://arxiv.org/abs/2209.10652). In a toy
  autoencoder x′ = ReLU(WᵀWx + b), with n sparse synthetic features
  compressed into m < n dimensions, a linear model keeps only the top-m
  features, but with the output ReLU and sparse enough features the model
  stores more features than dimensions ("superposition"), in
  non-orthogonal directions whose interference the ReLU and a negative
  bias filter out. Whether a feature is dropped, superposed or given a
  dedicated dimension changes discontinuously with sparsity and
  importance, and in the n = 2, m = 1 theory this is a first-order phase
  change. With uniform features the directions settle into uniform
  polytopes, with feature dimensionalities clustering at 3/4, 2/3, 1/2,
  2/5 and 3/8. A ReLU hidden layer creates a privileged basis in which
  monosemantic and polysemantic neurons coexist, and a model can compute
  |x| for more features than it has neurons. Everything is shown in toy
  models only, and the authors expect the geometry and learning-dynamics
  results to generalise least.

[NOTE-278](../notes.d/NOTE-278.md) is the close reading of 2026-09-29, and it placed the work: **Active** — worth reading as the founding statement of the superposition hypothesis and of the vocabulary the field now uses: features as directions, privileged versus non-privileged bases, polysemanticity as interference, and feature dimensionality. It is also the cleanest demonstration that a nonlinearity plus sparsity makes it optimal to store more features than dimensions. Its evidence is toy models alone, which the paper says plainly. Its phase-change and polytope results are exact only for n = 2, m = 1 and uniform features.
