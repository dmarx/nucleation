# THEORY-tmpyzyqe: Mo, Zheng and colleagues (2026) report that when LLMs must search the literature themselves rather than read a supplied set of papers, their scientific hypotheses separate more between models and improve about twice as fast across model generations, the gain coming from feasibility, clarity and specificity while LLM-judged originality is unchanged.

## The account

Mo, Zheng and colleagues (2026) report that when LLMs must search the
literature themselves rather than read a supplied set of papers, their
scientific hypotheses separate more between models and improve about twice
as fast across model generations, the gain coming from feasibility, clarity
and specificity while LLM-judged originality is unchanged.
