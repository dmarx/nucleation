summary: >-
  Zhang et al. (2026), AsynCodeBench: Benchmarking Collaboration of
  Asynchronous Multi-Agent Systems in Software Engineering. A benchmark of
  19 tasks from 16 real repositories in which a coding task is split among
  specialist agents and every cross-component dependency (52 directed
  dependencies, human-validated) has an executable Dependency Checker. Two
  measures: ADPR, the share of cross-agent dependencies ultimately
  satisfied, and DRS, the step at which each first becomes satisfied. Five
  execution protocols (Single; Serial handoffs; Async-Private, concurrent
  specialists in private workspaces; Async-Manager-RO, a read-only manager
  who inspects and coordinates; Async-Manager, a manager allowed bounded
  repair) are run on ten open-weight models. Coding performance and
  collaboration come apart: test pass rates can be high while dependencies
  stay unresolved, no protocol helps every model, and dependencies tend to
  resolve in bursts. Read for the exchange "luria experiment design".
