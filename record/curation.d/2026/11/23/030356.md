## Alternatives for the owner

- **What the study shows about predictors.** A, [CLAIM-tmpf0417](../../record/claims.d/CLAIM-tmpf0417.md): a
  predictor of productive nuclei needs the order and threshold of growth,
  since static closure is constant where V varies. B, [CLAIM-tmpddl2d](../../record/claims.d/CLAIM-tmpddl2d.md),
  objecting: the test system lacks coherent alternative branches, so the
  race reading's home case is untested. The filer leans to A for systems
  like the one tested, and grants B as a limit on A's generality.
- **The amendments.** The first registered predictor was degenerate on
  the test system and was amended before the full run; the amendment is
  recorded with its reasons. The owner may prefer to count the first test
  as the only pre-registered one, in which case the record holds one void
  test and two tests designed after looking.
