# THEORY-tmp8127k: Salemi et al. report that, for LLM agents answering data-science questions over large file collections, a main agent that broadcasts requests to a blackboard and lets file-holding helper agents decide whether to respond outperforms a matched design in which the main agent assigns subtasks to named helpers, in end-to-end accuracy and in file-discovery F1, with the advantage growing with the size of the collection, at roughly 1.8× the per-question cost.

## The account

Salemi et al. report that, for LLM agents answering data-science questions over large file collections, a main agent that broadcasts requests to a blackboard and lets file-holding helper agents decide whether to respond outperforms a matched design in which the main agent assigns subtasks to named helpers, in end-to-end accuracy and in file-discovery F1, with the advantage growing with the size of the collection, at roughly 1.8× the per-question cost.
