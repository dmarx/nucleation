# CLAIM-tmpi0o8t: Liveness is relative to roots, and partly developmental

## The claim

A29 §1. A tracing collector "begins with a set of roots and follows
references from them". For the record: "what are the roots of a living body
of inquiry?" A's candidates: current manuscripts, ongoing experiments,
explicitly maintained research questions, foundational commitments,
unresolved consequential objections, and protected alternative
perspectives.

Against reference counting: "An entire cluster of obsolete claims might
cite one another extensively. Reference counting would regard all of them
as highly connected. Root-based tracing would recognize that none
contributes to the activities we have explicitly chosen to maintain." In a
collector the same point is that counting cannot reclaim cycles.

The limit, in A's words: tracing "proves only that it is not reachable
through the declared maintenance relations from the current root set. That
is sufficient evidence for a *review candidate*, not for permanent
disposal."

## Five kinds of liveness

A29 VIII:

| Kind of liveness | Interpretation |
|---|---|
| Referential | Something currently depends on the object |
| Operational | The object supports present activity |
| Corrective | It supports possible reconsideration |
| Developmental | It can support the formation of new activity |
| Normative | There are independent reasons to preserve it |

"The last three cannot be adequately inferred from citation topology
alone." A collector's reachability is a conservative stand-in for future
use because future use is undecidable; the record has a further problem,
that "A new root can emerge around something that had no path from any
existing root."

## Developmental loss

A29 VIII states what a forgetting operation F costs as a change in the
inquiries realizable within a budget B and horizon T, from Q_{B,T}(R) to
Q_{B,T}(F(R)). "Forgetting can contract that set by destroying useful
knowledge. But it can also expand it by reducing retrieval costs,
eliminating redundant work, and enabling new abstractions. Neither outcome
is guaranteed."
