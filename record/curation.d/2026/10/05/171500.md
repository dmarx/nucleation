The owner asked for the audit [ADR-029](../../record/decisions.d/ADR-029.md) left open: whether the theories that
name each other without a declared relation are missing one, and whether
any declared `extends` is really a `presupposes`.

## How

A script listed every unordered pair of theories where one names the
other outside backticks and neither declares a relation to the other: 250
pairs. For each pair it collected both titles, statuses and tags, and
every paragraph in which one names the other. Five agents classified 50
pairs each against the four definitions, defaulting to none. A sixth
judged the 60 declared relations, defaulting to keep. I read the text
behind every proposal before taking it.

The pair count includes five false matches. A citation of an anthology
theory renders as a link whose target path ends in that anthology code's
file name, so the regular expression `THEORY-\d+` found this record's code
inside the anthology's link, and a theory citing the anthology's [THEORY-004](../../record/theory.d/THEORY-004.md)
looked as if it named this record's. A second run of the count has to drop
`ANTH-` citations and their targets first.

## What it says about the gap

Of the 245 real pairs, 241 stay undeclared, and in almost every case the document
already says why: a contrast, a parallel in another domain, a shared
source, a test not yet run. The gap the owner noticed is mostly the record
naming its neighbours, not the record failing to declare dependencies.

The part that was a real gap was the missing word. Most of the eleven
changes were already in the prose as "presupposes", "relies on" or "if it
fell, the argument would lose its premise", written before there was a
relation to declare them with.
