# LIT-963: Fundamental Limits of Perfect Concept Erasure

Somnath Basu Roy Chowdhury, Avinava Dubey, Ahmad Beirami, Rahul Kidambi, Nicholas Monath, Amr Ahmed and Snigdha Chaturvedi (2025), *arXiv:2503.20098* (AISTATS 2025).

## Key takeaways

*From the reading, [NOTE-820](../notes.d/NOTE-820.md).*

- **The cap.** If I(Z;A) = 0 then I(Z;X) = I(Z;X|A) ≤ H(X|A), with
  equality iff H(X|Z,A) = 0 (Lemma 3.3). It needs only A → X → Z.
- **When a deterministic map reaches it.** Only when every concept group
  has the same distribution up to permutation; then a bijection of each
  group onto a common distribution does it (Definition 4.1, Method 4.2,
  Appendices A.3–A.4).
- **The assumptions are strong.** Finite supports and disjoint groups
  make the concept a function of the representation. The cap is then
  H(X) − H(A).
- **One claim does not hold.** For unequal groups the paper says the
  cap is unreachable and calls the optimal output distribution an open
  question. A stochastic map built on a common refinement of the groups'
  distributions reaches the cap, so the impossibility holds only for
  deterministic maps.
- **The empirical part** (PEF against INLP, LEACE, FaRM, KRaM and DCA)
  is ML practice and carries the anthology-candidate flag.
