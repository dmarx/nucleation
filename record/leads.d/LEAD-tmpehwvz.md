# LEAD-tmpehwvz: Measure compensation and entrainment in a mode that is dynamically closed but not a weakly coupled block, to see whether the block test misses a unit

## What it would do

Find or simulate a system with a closed mode that is not a gap-isolated
block (a flux pattern or a field excitation), perturb it, and measure
whether it compensates and entrains; CASE-269's field testbed could carry
the arm for QUESTION-219.

Where the record names it:

- QUESTION-218: "If the mode compensates and entrains and the block test
  misses it, that meets CLAIM-157's defeated_if"
- QUESTION-219: "to a system where the block test fails"

## What would count

Compensation and entrainment where the block test sees no unit meets
CLAIM-157's defeated_if. Their absence says the block is the better unit
and closure tracks something else.
