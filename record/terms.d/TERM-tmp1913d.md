# TERM-tmp1913d: agent (at a level of description)

## Definition

Fix a level of description and a target. A factor of a system is an
**agent** there when it passes three tests:
1. **System.** It is one system ([TERM-tmpq5zvd](TERM-tmpq5zvd.md), [CLAIM-tmp8tsw5](../claims.d/CLAIM-tmp8tsw5.md)).
2. **Description.** A goal-directed description of it beats a device
   description by more than the Occam cost of the richer model ([LIT-tmpq7txx](../literature.d/LIT-tmpq7txx.md),
   priced as in [CLAIM-tmp45kkg](../claims.d/CLAIM-tmp45kkg.md)).
3. **Adaptation.** Its policy would change if its actions influenced the world
   differently ([LIT-tmpbu984](../literature.d/LIT-tmpbu984.md)).

The test is [CLAIM-tmpwv313](../claims.d/CLAIM-tmpwv313.md). Agency so defined is relative to the level and
target, and can be wrong given them.

## What it is not

- **Not every control system.** A bare thermostat is a control system and
  fails test 3. With its designers it passes ([CASE-tmp6ve1p](../cases.d/CASE-tmp6ve1p.md)).
- **Not a willed agent.** An agent need not have governance over several
  regimes. A trained policy's training process is an agent on Kenton et
  al.'s account, and need not be willed. That is [TERM-tmpllrr1](TERM-tmpllrr1.md).
- **Not a self** ([TERM-tmpg0hhr](TERM-tmpg0hhr.md)).
