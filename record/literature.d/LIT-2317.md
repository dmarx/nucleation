  Majumder et al. (2024), DiscoveryBench: Towards Data-Driven Discovery with
  Large Language Models. DiscoveryBench asks whether LLM agents can search
  for and verify hypotheses from datasets alone. A data-driven hypothesis is
  a sentence whose truth a verification procedure can infer from a dataset;
  it decomposes into sub-hypotheses, each with a context (boundary
  conditions), variables and a relationship. Tasks give a dataset, metadata
  and a goal formed by masking one of these dimensions of a target
  hypothesis. DB-REAL has 264 tasks from over 20 published papers in six
  domains (sociology, biology, humanities, economics, engineering,
  meta-science), each with a replicated workflow; DB-SYNTH has 903
  LLM-generated tasks across 48 domains built from synthetic semantic trees
  with controllable difficulty. Read for the exchange "luria experiment
