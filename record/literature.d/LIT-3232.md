# LIT-3232: Intuitionistic Type Theory

Martin-Löf, P. (1984). *Intuitionistic Type Theory.* Notes by Giovanni
Sambin of a series of lectures given in Padua, June 1980. Studies in Proof
Theory, Lecture Notes. Bibliopolis, Naples. ix + 91 pp.

## Key takeaways

- Four forms of judgement, "(1) A is a set ... (3) a is an element of the
  set A (a ∈ A)" (p. 5); "in ordinary set theory a ∈ b and a = b are
  propositions, while they are judgements here" (p. 5).
- Each form has four readings: set, proposition, intention (Heyting) and
  problem (Kolmogorov). "a is a method ..." can be read as "a is a
  program ...", completed "... which meets the specification A" (p. 6).
- "a set A is defined by prescribing how a canonical element of A is
  formed as well as how two equal canonical elements of A are formed"
  (p. 8); an element is "a method (or program) which, when executed,
  yields a canonical element of A as result" (p. 9).
- Propositions and sets are identified: "This is the formulae-as-types
  (propositions-as-sets) interpretation on which intuitionistic type
  theory is based" (p. 13).
- A canonical proof of (∃x ∈ A)B(x) "is a pair (a,b), where b is a proof
  of the fact that a satisfies B" (p. 42); the set of a ∈ A such that
  B(a) has such pairs as its elements (p. 53).
- A universe is "the least set closed under certain specified set forming
  operations" (p. 87); "there can be no set of all sets" (p. 87), and
  "U itself is not an elemnt [sic] of U" (p. 90).
