summary: >-
  Aerts & Gabora (2005), DOI-10.1108/03684920510575807. Aerts & Gabora
  embed the "pet" data in ℂ¹⁴⁰⁰. Each of 1,400 "basic contexts" is one
  vector of an orthonormal basis, the ground state is the uniform
  superposition, and each context is the projector onto the span of its
  basic contexts. The Born rule then returns the measured frequencies as
  counting ratios, for example cat under "chewing a bone" = 75/303 = 0.25.
  "Pet fish" is modelled as the entangled state Σ_{u∈E} |u⟩⊗|u⟩/√100 in
  ℂ¹⁴⁰⁰⊗ℂ⁴⁰⁸, so that collapsing "pet" to goldfish collapses "fish" to
  goldfish too. Every projector in the model is diagonal in one basis, so
  the fitted model is a classical probability space in quantum notation,
  which the authors half-concede (a "quantization … of this set
  theoretical model", §3.3). Two of the chosen counts are infeasible:
  parrot and guppy.
