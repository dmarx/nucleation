# CLAIM-tmp3qyzh: Any individuation built on sufficiency is relative to the target it is sufficient for: fix the outcomes differently and a different partition wins, so no boundary drawn this way is universal

## The claim

From [MOM-POS-001](https://github.com/dmarx/mathematics-of-meaning/blob/main/record/positions.d/POS-001.md). A statistic T is sufficient *for predicting Y*. With no Y,
the notion picks out nothing. So every individuation built on sufficiency,
whether of an identity, a universal or a system, inherits a parameter it
must fix, and fixing it makes the result relative to the choice. MOM's
case: sufficient for locomotion and metabolism, "organism" wins; for niche,
"animal" does. Biological taxon and ecological niche cross-cut, so no
partition is universal on both.

## Why this record holds it, and what it does here

It holds by definition. Here it disciplines the boundary claims filed beside
it:
- **The Occam-priced test ([CLAIM-tmp45kkg](CLAIM-tmp45kkg.md))** takes its candidate direction and
  prior from a model chosen for some purpose.
- **The persistence test ([CLAIM-tmpdqsrb](CLAIM-tmpdqsrb.md))** depends on which γ.

So a verdict that the dancing couple is one system ([CLAIM-tmpygda8](CLAIM-tmpygda8.md)) is a
verdict relative to a stated target, such as predicting the dance's next
beat. [MOM-LIT-023](https://github.com/dmarx/mathematics-of-meaning/blob/main/record/literature.d/LIT-023.md) and this record's [LIT-603](../literature.d/LIT-603.md) make the same point about
Markov blankets: a blanket individuates nothing until the variables are
fixed.

## What it does not say

- **That boundaries are arbitrary.** Given a target, the criteria decide, and
  can be wrong.
- **That MOM's further conclusion applies here.** MOM argues this costs its
  source corpus its Platonism about universals. This record makes no such
  realist commitment, so the position is a caution here, not a defeater.
