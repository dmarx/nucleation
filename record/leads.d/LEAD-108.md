# LEAD-108: State one cost model for stored work and check whether it prices the cockpit's speed bugs, a filed argument and a LEGO bin with the same terms

## What it would do

Write a cost model with a term for how predictable the later query is, a
retrieval cost that includes search, a staleness or bias cost on reuse,
and a term for the erosion of the alternative; separate operational
feasibility, lifetime efficiency and distributed costs, as [CLAIM-761](../claims.d/CLAIM-761.md)
begins to; then price the three cases with it.

Where the record names it:

- [QUESTION-095](../questions.d/QUESTION-095.md): "The four strategies would then be regimes of one trade,
  which is the owner's conjecture, stated so that it can fail."
- [QUESTION-114](../questions.d/QUESTION-114.md): "does its cost model price the cockpit's bugs, a filed
  argument and a LEGO bin with the same terms"

## What would count

One model that prices all three with the same terms answers [QUESTION-114](../questions.d/QUESTION-114.md)
and states the owner's conjecture in [QUESTION-095](../questions.d/QUESTION-095.md) so that it can fail. A
case it cannot price without a new term is a counterexample to the single
trade.
