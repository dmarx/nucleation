# THEORY-tmpn3ohs: Stute tells, as his own experience, a departed graduate student's compiler Trojan horse that restored a program's hateful subliminal messages on every compile and restored itself when the compiler was rebuilt from clean source, removed only by installing a compiler binary from another machine

## The account

A program's author, a former graduate student, made it flash "some white
supremacy message" before each question. Cleaning the source failed,
recompiling the libraries failed, and rebuilding the compiler from clean
source failed: "The ex-grad student had poisoned the compiler to poison
itself when it was recompiled." It ended when "a new binary version of the
compiler" from another machine was installed.

## Evidence

The answer itself ([NOTE-tmp0akth](../notes.d/NOTE-tmp0akth.md)), told as first-hand and unverifiable.
