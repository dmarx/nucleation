  orthonormal set {φ} on (0, 1) of functions taking only the values ±1,
  recursively by (2) and explicitly by (3)–(4). In binary x = Σ a_i/2^i,
  the functions are signed products (−1)^{a_{i₁}+…+a_{i_r}}; the nth has
  exactly n sign changes. It proves Fourier-like properties: uniform
  convergence for continuous F with the terms grouped in dyadic blocks
  (Thm II); pointwise convergence to ½[F(a−0)+F(a+0)] for bounded
  variation (Thm IV); localisation (Thm V); uniform Cesàro summability for
  continuous F (Thm VII); a continuous function with a divergent φ-series
  at any chosen point (Thm VIII); and uniqueness of expansions (Thms
