# LEAD-036: Model or trace the loop by which activity-based funding erodes rarely used capability, against a control that decouples maintenance funding from observed activity

## What it would do

Simulate the loop with and without decoupling, or find a history that
shows it.

Where the record names it:

- [QUESTION-386](../questions.d/QUESTION-386.md): "a model run or an organizational history showing the loop
  at work, against a control in which maintenance funding is decoupled from
  observed activity."

## What would count

Capability that erodes only under coupling answers [QUESTION-386](../questions.d/QUESTION-386.md) beyond
[CLAIM-577](../claims.d/CLAIM-577.md)'s pure case.

## Note of 2026-11-22: carried out by simulation

Done by the first route, a simulation; no organizational history was sought. A's model from [QUESTION-386](../questions.d/QUESTION-386.md) was run with a commitment threshold as the coverage feedback, at five rarities at fixed expected funding, with the activity signal over one quarter and over a year, against maintenance funded apart from activity, the same money untied, and an ablation without coverage feedback ([CASE-343](../cases.d/CASE-343.md); code under scratch/studies/lead-036/). What the lead says would count was found: where the base budget alone sustains competence below the commitment threshold, the capability eroded for good only under coupling, more often the rarer its use, and never under decoupling ([CLAIM-921](../claims.d/CLAIM-921.md)). What remains is the lead's other route, an organizational history showing the loop, and a run in which practice counts as activity under this rule. Stage and status are left to the owner.
