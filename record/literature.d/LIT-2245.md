# LIT-2245: Common noise-induced group-level synchronization between uncoupled groups of oscillators

Tae-Wook Ko (2026). "Common noise-induced group-level synchronization between uncoupled groups of oscillators." *Physica A* 701: 132013. [ARXIV-2605.29529](https://arxiv.org/abs/2605.29529) DOI-10.1016/j.physa.2026.132013.

## Key takeaways

Read on 2026-11-22 (NOTE-tmpw116e). Synchrony of the collective order parameters of two groups with no coupling between them, induced by a shared common noise alone, even when each group's internal synchrony fluctuates widely; intra-group coupling can weaken it. A's description is borne out within the model.
