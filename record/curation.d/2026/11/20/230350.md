## What prompted it

The assistant's answer at A2 had said that contraction narrows by
forgetting the source and stabilization by anchoring to it, and that "the
record seems to rely on each for a different job". The owner, at U5: "Are
you sure these are different things? I'm wondering if maybe it's the same
phenomenon, and maybe one description generalizes the other. Isn't
stabilization just monotone contraction? maybe there's a formalization we
could lean on that would make this clearer for me." At U6, after the
assistant agreed and proposed the formalization: "yes, rewrite them on the
branch, and doesn't hesitate to add any other additional items that might
help document these developments".

The owner was right. The assistant's answer: one contraction; what a chain
keeps of its start is exactly what its steps conserve; anchoring is having
the source's features in the conserved part. "Monotone" is true of both
cases and does not separate them.

## Where the record already held it

Searching for the formalization found that the record had most of it,
which the assistant's answer at A3 had not known when it was written:

- **CLAIM-635** (demonstrated, Proposed): an exactly conserved observable
  keeps information about the start bounded below at every generation, and
  "a bounded conservation defect does not prevent forgetting". This is the
  central result; A3 had offered "anchoring needs ε exactly zero" as a
  point the assistant had missed, and the record already held it.
- **CLAIM-107**: the exact criterion K f = f and the martingale.
- **THEORY-960** (DeGroot): the consensus keeps exactly πF, a conserved
  average of the start.
- **THEORY-2044** (Wang and Slotine, partial contraction): what lies along
  the contracted-to property is kept, set by initial conditions.
- **THEORY-2043** (Lohmiller and Slotine): global contraction forgets
  initial conditions.
- **QUESTION-006**: which observables actual kernels conserve.
- **CLAIM-094**: a harmonic observable conserves only its mean.

Not held: semicontraction (contraction with respect to a seminorm), which
the assistant named from memory. Two papers were identified on the arXiv
API and Crossref and registered (below).

## The check behind CLAIM-tmpw6wkt

Run under `python3 -I` on 2026-11-20 with numpy:

    # check: I(x0;xn) for x_{n+1} = a x_n + (1-a) c + sigma*xi, x0 ~ N(0, s^2)
    import numpy as np
    rng = np.random.default_rng(0)
    s, sig, c, M = 1.0, 0.1, 3.0, 200_000
    def closed(a, n):
        V = n*sig**2 if a == 1 else sig**2*(1-a**(2*n))/(1-a**2)
        return 0.5*np.log1p(a**(2*n)*s**2/V)
    for a in (1.0, 0.9, 0.5):
        x0 = rng.normal(0, s, M); x = x0.copy()
        for n in range(1, 401):
            x = a*x + (1-a)*c + sig*rng.normal(size=M)
            if n in (10, 100, 400):
                r = np.corrcoef(x0, x)[0, 1]; emp = -0.5*np.log(1-r*r)
                print(f"a={a} n={n} I_closed={closed(a,n):.4g} I_emp={emp:.4g} n*I={n*closed(a,n):.3f}")

Output: at a = 1, closed 1.199, 0.3466, 0.1116 against empirical 1.201,
0.345, 0.1112 (n·I = 12.0, 34.7, 44.6, rising toward 50); at a = 0.9, n = 10,
0.6446 against 0.6431; every other closed value is below the empirical
sampling floor of about 10⁻⁵ nats, as the geometric rate predicts.
