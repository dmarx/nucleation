# LEAD-tmpwq9wf: Find or run an adequately powered Contextuality-by-Default test on human pragmatic judgements, with signalling accounted for and outcome coding fixed in advance

## What it would do

Check the literature for such a test; failing one, design it with
signalling estimators, a power analysis and the outcome coding fixed
before data.

Where the record names it:

- CLAIM-009: "It waits on a Contextuality-by-Default analysis of human
  pragmatic judgements that robustly finds or excludes contextuality."
- CLAIM-105: "documents that no adequately powered CbD test on pragmatic
  judgements has been run."

## What would count

Robust contextuality supports CLAIM-009 and defeats CLAIM-325's null;
robust absence does the reverse.
