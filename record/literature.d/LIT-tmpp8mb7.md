  presents a draft, consensus "abstract model" for an Argument Interchange
  Format so that argumentation tools and multi-agent systems can exchange
  arguments. It is organized as core ontology plus extensions, an abstract
  model plus several concrete reifications. The core has three groups:
  argument networks, communication (locutions, protocols) and context
  (participants, dialogue type, commitment stores, theory). An argument
  network is a directed graph (cycles allowed) of information nodes
  (I-nodes, claims) and scheme-application nodes (S-nodes):
  rule-of-inference applications (RA), preference applications (PA) and
