# THEORY-tmpvuz7f: Xue and colleagues (2026) find, by running each later task with an agent's retained memory, skills and history switched on and off in fresh sessions, that personal LLM agents do improve from retained experience but unevenly by capability, that equal score gains can rest on different persistence pathways, and that a typical failure is a corrected value whose old version stays active in the next session. 2 and 4.3 the paired on/off design, the Hermes vs nanobot mechanism-evidence contrast at equal Δ, and the Update-failure sentence

## The account

Xue and colleagues (2026) find, by running each later task with an agent's
retained memory, skills and history switched on and off in fresh sessions,
that personal LLM agents do improve from retained experience but unevenly by
capability, that equal score gains can rest on different persistence
pathways, and that a typical failure is a corrected value whose old version
stays active in the next session.

2 and 4.3 the paired
on/off design, the Hermes vs nanobot mechanism-evidence contrast at equal Δ,
and the Update-failure sentence.
