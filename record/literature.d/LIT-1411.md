  overparameterized linear regression tasks, drawn uniformly from N ground
  truths each carrying a feature signal a linear gate can read, a top-1
  MoE whose gate is trained on a locality loss plus a Switch-style
  balancing loss sorts identically initialized experts into one set per
  task (or task cluster) within about M/η rounds. If gate training
  continues, the balancing loss eventually erases the gaps between gate
  outputs and routing fails, so the gate is frozen once the gaps settle;
  forgetting then decays as 1/t, and extra experts only lengthen
  exploration. Small deep-network runs show the same pattern.

# LIT-1411: Theory on Mixture-of-Experts in Continual Learning

Li, H., Lin, S., Duan, L., Liang, Y. and Shroff, N. B. (2025). Theory on mixture-of-experts in continual learning. *ICLR 2025*. arXiv:2406.16437.

Read on 2026-10-29 ([NOTE-tmphutxm](../notes.d/NOTE-tmphutxm.md)): the main paper and the experimental
appendix in full, the proofs not checked.

## Why this is here

The exchange cited it for [CASE-117](../cases.d/CASE-117.md): specialization emerging among identically parameterized operators whose routing and training co-evolve over a changing task distribution is what the paper proves for a gated MoE, and its result that the gate must stop updating for convergence is a condition [CASE-117](../cases.d/CASE-117.md) should test. The exchange gave no description to check. It carries the anthology-candidate flag ([ADR-005](../decisions.d/ADR-005.md)) because the abstract draws practical design guidance for MoE training.
