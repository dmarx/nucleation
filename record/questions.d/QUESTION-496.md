# QUESTION-496: How should the record triage its open questions, so that the questions it hopes to answer choose the method, given that experiment is not the only way to advance them?

## The question

U38: "we should probably prioritize experimentation based on which open
questions we hope to answer. I'm not sure what a good procedure for
triaging them would be, but given the scope and breadth of material we're
synthesizing here, I don't think we should feel like experimentation is
the only opportunity to progress science here. we have a lot of value
here from a philosophy perspective already."

The record files questions by line and gives many a section on what would
answer them, but it has no procedure for deciding which to work on next,
or by which method.

## What would answer it

A procedure the owner adopts, with a decision recording it, and its first
application to the record's open questions. [CLAIM-763](../claims.d/CLAIM-763.md) is a
candidate. Part of the question is whether such a procedure should rank
at all, or only order questions by what each unlocks.
