# LEAD-085: Run governed schema adaptation with a performance-gated arm, including its secondary estimand on routine tasks

## What it would do

Run [CASE-253](../cases.d/CASE-253.md): agents with fixed information, tools and budget, schema
modifiability and change governance varied independently, a
performance-gated arm, and routine tasks on which no change is warranted.

Where the record names it:

- [QUESTION-458](../questions.d/QUESTION-458.md): "A study that holds the information, tools and budget
  fixed and varies schema modifiability and change governance independently,
  such as [CASE-253](../cases.d/CASE-253.md), with a performance-gated arm."
- [QUESTION-458](../questions.d/QUESTION-458.md): "Part 2 is untouched: none varies governance against
  performance-gating"
- [CLAIM-665](../claims.d/CLAIM-665.md): "The study that would test it is [CASE-253](../cases.d/CASE-253.md)'s secondary
  estimand on tasks where no schema change is warranted"

## What would count

Governed adaptation beating both a fixed schema and performance-gated
change supports [CLAIM-667](../claims.d/CLAIM-667.md); harm on routine tasks supports [CLAIM-665](../claims.d/CLAIM-665.md). No
difference from gating answers [QUESTION-458](../questions.d/QUESTION-458.md)'s second part against
governance.
