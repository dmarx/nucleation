# THEORY-tmpdjm1o: Srikanth et al. (2026) report that AIDE², an outer-loop agent that rewrites a tree-search research agent's code and keeps a rewrite only when it improves a private held-out grade at fixed per-task budget, accepted seven rewrites in an eight-day run that raised the grade from 0.703 to 0.778, that the final agent matched or exceeded a human-engineered production agent on four external benchmarks, and that a direct test of whether a discovered agent drives the loop better than the human-engineered one was inconclusive. `

## The account

Srikanth et al. (2026) report that AIDE², an outer-loop agent that rewrites a tree-search research agent's code and keeps a rewrite only when it improves a private held-out grade at fixed per-task budget, accepted seven rewrites in an eight-day run that raised the grade from 0.703 to 0.778, that the final agent matched or exceeded a human-engineered production agent on four external benchmarks, and that a direct test of whether a discovered agent drives the loop better than the human-engineered one was inconclusive.
