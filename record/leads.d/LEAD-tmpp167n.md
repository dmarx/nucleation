# LEAD-tmpp167n: Compare an earlier and a later improver of a record-keeping collective from the same fresh state at the same budget, then damage its diagnostic machinery

## What it would do

Run CASE-255, which adapts CASE-186: let a collective improve its
procedures over generations, transplant an earlier and a later improver
onto the same fresh state at equal budget, then damage the diagnostic
machinery.

Where the record names it:

- QUESTION-457: "A study in which a collective improves its procedures
  over generations, an earlier and a later improvement procedure are each
  applied to the same fresh starting state at the same budget, and the
  collective's diagnostic machinery is then damaged"
- QUESTION-388: "a governing rule's change must alter behaviour under
  controlled later tasks"

## What would count

The later improver doing better from the same start, and losing that
advantage when diagnosis is damaged, answers QUESTION-457 for the
collective; QUESTION-457 itself warns that it does not establish
independent self-governance.
