  Yin et al. (2024), Gödel Agent: A Self-Referential Agent Framework for
  Recursive Self-Improvement. Gödel Agent is an LLM agent that can read and
  rewrite its own running code, including the code that analyses and
  modifies itself, by inspecting Python runtime memory and monkey patching;
  its main loop is a recursive function so that rewritten logic takes effect
  in the next call. Given only an environment description, a feedback
  mechanism and a chain-of-thought starting policy, it improves its task
  policy on DROP, MGSM, MMLU and GPQA, matching or beating hand-designed
  agents and Meta Agent Search (a meta-learning approach with a fixed
  meta-algorithm). In 100 optimisation trials on MGSM it often makes harmful

  worse than its starting policy in 14% of trials. Read for the exchange
