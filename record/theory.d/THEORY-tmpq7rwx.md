# THEORY-tmpq7rwx: Rudner, Lindner, Berg and Levin show that in periodically driven, non-interacting two-dimensional lattice systems the Chern numbers of the Floquet bands do not determine the chiral edge modes, which can exist when every band's Chern number is zero, and that a winding number of the bulk evolution operator over the whole driving period gives the net number of chiral edge modes in each quasi-energy gap

## The account

In a static system the spectrum is bounded, so band Chern numbers fix the net number of chiral edge modes in each gap. In a periodically driven system quasi-energy is defined on a circle, so an edge mode can wind through the zone edge at ε = π/T. Chiral edge modes then exist with all Floquet Chern numbers zero. The authors' five-step hopping model shows this at its simplest. Its bulk Floquet operator is the identity, yet particles move one unit cell per cycle along an edge, and the reversed cycle has the same Floquet operator with the opposite edge chirality. The invariant that fixes the edge count is a winding number W of U(k, t) over momentum and the whole period, after deforming to an evolution with trivial Floquet operator. Numerical spectra in strip geometries agree with it.

## What it does not show

- Interfaces between two differently driven regions: only edges against vacuum are treated.
- Anything about interactions, filling of the edge states or heating. Filling is explicitly left aside.
- A full classification with symmetries ("yet to be developed").
- A strict gap for realistic slow driving: multi-photon resonances leave none, and the edge states are well defined only for weak driving.
