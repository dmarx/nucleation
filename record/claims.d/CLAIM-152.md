# CLAIM-152: Any individuation built on sufficiency is relative to the target it is sufficient for: fix the outcomes differently and a different partition wins, so no boundary drawn this way is universal

## The claim

From [MOM-POS-001](https://github.com/dmarx/mathematics-of-meaning/blob/main/record/positions.d/POS-001.md). A statistic T is sufficient *for predicting Y*. With no Y,
the notion picks out nothing. So every individuation built on sufficiency,
whether of an identity, a universal or a system, inherits a parameter it
must fix, and fixing it makes the result relative to the choice. MOM's
case: sufficient for locomotion and metabolism, "organism" wins; for niche,
"animal" does. Biological taxon and ecological niche cross-cut, so no
partition is universal on both.

## Why this record holds it, and what it does here

It holds by definition. Here it disciplines the boundary claims filed beside
it:
- **The Occam-priced test ([CLAIM-154](CLAIM-154.md))** takes its candidate direction and
  prior from a model chosen for some purpose.
- **The persistence test ([CLAIM-161](CLAIM-161.md))** depends on which γ.

So a verdict that the dancing couple is one system ([TERM-049](../terms.d/TERM-049.md)<!-- ref::uses: TERM-049 -->) ([CLAIM-175](CLAIM-175.md)) is a
verdict relative to a stated target, such as predicting the dance's next
beat. [MOM-LIT-023](https://github.com/dmarx/mathematics-of-meaning/blob/main/record/literature.d/LIT-023.md) and this record's [LIT-603](../literature.d/LIT-603.md) make the same point about
Markov blankets: a blanket individuates nothing until the variables are
fixed.

## What it does not say

- **That boundaries are arbitrary.** Given a target, the criteria decide, and
  can be wrong.
- **That MOM's further conclusion applies here.** MOM argues this costs its
  source corpus its Platonism about universals. This record makes no such
  realist commitment, so the position is a caution here, not a defeater.

## Note of 2026-10-12: evidence now linked

Four THEORYs now ground this claim:

- [THEORY-194](../theory.d/THEORY-194.md): which variables a compression keeps is set by what it must stay informative about.
- [THEORY-202](../theory.d/THEORY-202.md): the variables a renormalization keeps must be fixed by a stated target.
- [THEORY-066](../theory.d/THEORY-066.md): the blanket formalism takes the internal set as input and never outputs it.
- [THEORY-073](../theory.d/THEORY-073.md): where a blanket falls is fixed by modelling choices made before it is found.

The body already made [THEORY-066](../theory.d/THEORY-066.md)'s point about Markov blankets through [LIT-603](../literature.d/LIT-603.md).

## Note of 2026-10-12: a competent-uptake standard on the pragmatic-transport line, left to the owner

PR [#121](https://github.com/dmarx/nucleation/issues/121) filed [CLAIM-tmpawn12](CLAIM-tmpawn12.md) (Proposed), which takes as its standard of
sufficiency "the uptake of competent participants who know the standings
and norms in play". That is close to the candidate this claim's defeat
condition names and calls circular, "what a competent user must predict".
[TERM-040](../terms.d/TERM-040.md) version 2 and [CLAIM-tmp3wo5j](CLAIM-tmp3wo5j.md) take up the same standard.
[CLAIM-tmpawn12](CLAIM-tmpawn12.md) grounds it in [CLAIM-151](CLAIM-151.md)'s partial constitution of the act
by uptake. Neither entry says whether that grounding is an independent
argument in this claim's sense or the circular case, and the question is
left to the owner.

## Note of 2026-10-12: the interlocutor's reading, as advice
