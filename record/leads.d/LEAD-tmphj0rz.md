# LEAD-tmphj0rz: Run the coupling, correspondence-map and revision-apparatus network study with its three added arms, including displacing a shared drive for one member only

## What it would do

Run [CASE-179](../cases.d/CASE-179.md) with A12's three arms, and add the intervention [QUESTION-063](../questions.d/QUESTION-063.md)
asks for: displace the shared drive for one member only, perturb one
member and measure the others, and say which of [QUESTION-035](../questions.d/QUESTION-035.md)'s tests can
see the difference between common drive and coupling.

Where the record names it:

- [ARG-072](../arguments.d/ARG-072.md): "That project is [CASE-179](../cases.d/CASE-179.md)'s study with the three arms A12 adds"
- [QUESTION-063](../questions.d/QUESTION-063.md): "Displace the shared drive for one member only and see
  whether the others follow. Perturb one member and measure the others."

## What would count

Compatibility, attraction, boundary constraint, individuation and revision
coming apart across arms answers [QUESTION-319](../questions.d/QUESTION-319.md) and meets or misses
[CLAIM-616](../claims.d/CLAIM-616.md)'s defeat condition. Members following a displaced drive only
through coupling separates coupling from common drive for [QUESTION-063](../questions.d/QUESTION-063.md).
