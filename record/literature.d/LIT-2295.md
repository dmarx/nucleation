  Agentic Reasoning on Scientific Literature. PaperArena is a benchmark of
  784 expert-curated questions over a corpus of 14,435 open-access AI papers
  that require reading several papers, using tools (PDF parsing, retrieval,
  web search, code execution, citation lookup) and combining the results. A
  platform, PaperArena-Hub, runs a ReAct-style single agent and a
  centralised multi-agent workflow (a manager plans and delegates to workers
  with separate contexts). The best configuration, Gemini 2.5 Pro in the
  multi-agent workflow, averages 38.78% (18.47% on the hard subset) against
  83.5% for a Ph.D. expert. Agents overuse general tools (code, web search),
  plan inefficiently, and a single agent given the minimal viable tool chain
