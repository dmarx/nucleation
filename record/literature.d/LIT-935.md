# LIT-935: The Origins of Representation Manifolds in Large Language Models

Alexander Modell, Patrick Rubin-Delanchy and Nick Whiteley (2025), *arXiv:2505.18235*.

## Key takeaways

*From the reading, [NOTE-802](../notes.d/NOTE-802.md).*

- **Two hypotheses, two levels.** Hypothesis 1: a continuous invertible
  map ϕ_f from the feature's compact metric space onto the sphere, which
  makes the representation homeomorphic to the feature (Proposition 1).
  Hypothesis 2: locally, CosSim(ϕ_f(z), ϕ_f(z′)) = g_f(d_f(z, z′)²) with
  g_f ∈ C² and g_f′(0) < 0.
- **Theorem 1.** Under both, L(ϕ_f ∘ η) = √(−2g_f′(0)) L(η) for every
  rectifiable path η. Shortest paths on the manifold measure the feature
  up to a unit, without knowing g. The proof (App. B) is a partition
  argument with a second-order error per step, and checks out. It
  recovers the length metric d_f induces, which is d_f on a length space.
- **The evidence.**
  - GPT-2-small layer-7 years: in order along a neighbour-graph curve
    (Kendall 0.97, Spearman above 0.99).
  - Not isometric to |x − y|. Isometric to log(2019 − year) (ρ = 0.99,
    ξ = 0.84).
  - Dates in a text-embedding model: ρ = 0.97 against the circular
    metric. Colours: weakly plausible.
  - Mistral 7B's month and weekday loops weave through a third principal
    component that the published 2-D view hides.
- **What it does not do.** It gives no mechanism for either hypothesis.
  §2.4's argument from linear readability is informal. It supplies each
  candidate metric by hand, which the authors call "clearly not
  scalable". It recovers a metric, not a group.
