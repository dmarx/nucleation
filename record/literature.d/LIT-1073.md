# LIT-1073: The soft constraints hypothesis: A rational analysis approach to resource allocation for interactive behavior

Gray, W. D., Sims, C. R., Fu, W.-T. and Schoelles, M. J. (2006). The soft constraints hypothesis: A rational analysis approach to resource allocation for interactive behavior. *Psychological Review* 113(3), 461–482. DOI 10.1037/0033-295X.113.3.461

## Key takeaways

Read in full ([NOTE-868](../notes.d/NOTE-868.md)). In a Blocks World copying task where the model pattern was hidden and opening it cost a lockout of 0 to 3,200 ms, people opened it less often, kept it open longer, and placed more blocks after the first look as the lockout rose, and the trend was graded down to differences of tens of milliseconds. An Ideal Performer Model that chooses how many blocks to encode per look (ENCODE-1 to ENCODE-8) by Q-learning, with the only reward being negative time and memory given by ACT-R's base-level activation, retrieval-threshold and latency equations, fits four measures from Experiment 3 with three memory parameters and one softmax noise parameter fitted on one of them. The authors read this as support for choosing between head and world by time alone, against a minimum memory hypothesis, which they concede no one has stated precisely enough to model. The model's only memory costs are encoding time, retrieval time and forgetting; it has no term for anything carried across trials, for a retrieved item being wrong, or for the world changing.

## Why this is here

Turned up by the citation search on [QUESTION-095](../questions.d/QUESTION-095.md) (amortized retrieval as amortized computation) and registered at the owner's request. The nearest formal cost model for head versus world, extending Gray and Fu 2004 ([LIT-1058](LIT-1058.md)).
