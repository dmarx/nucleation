## The account

Romera-Paredes and colleagues report that FunSearch, an evolutionary loop pairing a frozen
code-generating LLM with a fixed programmatic evaluator, found a cap set of size 512 in dimension
8, larger than previously known, and new online bin-packing heuristics, and that it works best
where an efficient evaluator with graded scores and a program skeleton are available.
