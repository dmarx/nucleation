  Hegde et al. (2025), A change language for ontologies and knowledge
  graphs. Ontologies and knowledge graphs change constantly, yet there is
  "no single agreed-upon way" to represent or communicate changes. KGCL is a
  LinkML data model with a taxonomy of change types (node changes such as
  rename, obsolete, new synonym, definition change; edge changes such as
  edge creation, deletion, node move, predicate change), a controlled
  natural language with a Lark grammar (rename ENVO:01000575 from 'wax' to
  'oil'), and serializations. The same representation serves as a
  prospective patch ("apply") and a retrospective diff. Tools: Ontobot, a
  GitHub Action that turns a KGCL request in an issue into a pull request
  that a curator must approve; a BioPortal widget that files such issues;
  OAK and ROBOT apply/diff commands. Read for the exchange "luria experiment
