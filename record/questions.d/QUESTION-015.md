# QUESTION-015: Given an independently warranted agent with several available action-generating regimes, what maintained relations govern which of them becomes practically effective?

## Why it is a question

Frankfurt separates having a desire from its being the effective will, and
asks which desire the agent wants to be effective. Neither tells us what makes
one regime rather than another acquire practical control. The question is
asked only of an agent already warranted on other grounds ([CLAIM-080](../claims.d/CLAIM-080.md));
whether a collective is one is [QUESTION-009](QUESTION-009.md), set aside.

## What would count as an answer

An organizational relation that, intervened on while the competing regimes are
held fixed, changes which regime becomes effective, and does so across
different realizers (the intervention criterion, Section 3.8).
