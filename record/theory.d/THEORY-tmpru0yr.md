# THEORY-tmpru0yr: The OAEI 2026 campaign page sets out a yearly shared evaluation, run since 2004, of systems that align pairs of separately built ontologies and instance sets against reference alignments, across about twenty tracks

## The account

The OAEI 2026 campaign page sets out a yearly shared evaluation, run since 2004, of systems that align pairs of separately built ontologies and instance sets against reference alignments, across about twenty tracks. Systems must run on every track and may not adapt to track-specific features. None of its 2026 tracks evaluates the evolution or versioning of a single ontology.
