summary: >-
  Stewart, Golubitsky & Pivato (2003), SIAM J. Appl. Dyn. Syst. 2(4).
  In a coupled cell network, a typed directed graph whose admissible
  dynamics give each cell an arbitrary smooth function of its input set,
  the same for cells with isomorphic inputs, a synchrony pattern is
  invariant under every admissible vector field iff its equivalence
  relation is balanced: equivalent cells receive the same number of
  inputs from each class along each arrow type (Theorem 6.5). Symmetry
  gives balance but is not needed, so robust synchrony occurs in
  networks with no symmetry and among cells with no arrows between them.
  The dynamics on a balanced subspace are admissible for a quotient
  network (Theorem 9.2), which can have symmetry the original lacks;
  not every quotient field lifts. The paper studies "existence, not
  stability".

# LIT-1674: Symmetry Groupoids and Patterns of Synchrony in Coupled Cell Networks

Stewart, I., Golubitsky, M., & Pivato, M. (2003). Symmetry groupoids and patterns of synchrony in coupled cell networks. *SIAM Journal on Applied Dynamical Systems*, 2(4), 609–646. doi:10.1137/S1111111103419896.

Read in full on 2026-10-27 ([NOTE-1217](../notes.d/NOTE-1217.md)).

## Why this is here

A22 §7 used it for the distinction between an invariant organization and
an attracting one: network architecture fixes which synchrony patterns
are possible, and dynamical stability which are realized. The record's
[THEORY-276](../theory.d/THEORY-276.md) is the symmetry-group case it generalizes. It bears on
[CLAIM-471](../claims.d/CLAIM-471.md) and [QUESTION-063](../questions.d/QUESTION-063.md).
