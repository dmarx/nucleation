# CLAIM-tmpnf9by: Scoring against a null is a case of certifying categories by a model of the effect of using them, the model being the null's account of what the measure shows without the effect

**Reading (b), an alternative to CLAIM-tmpz5c3x.** Comparing a reading with a null is comparing the measure with and without the learned categories, so it is a model of their effect, a degenerate one that gives the zero-effect baseline. On this reading the manuscript's list of three routes stands, and CLAIM-tmpfls41 says only that the second route must include a null.

**What would favour it.** Cases where the null is a model of the same system with the learning removed (an untrained network of the same width, a shuffled target), which is a model of what the categories contribute.

The wording is the assistant's (Claude, in this session); adopting it is the owner's call.
