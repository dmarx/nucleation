# LEAD-183: Test a non-monotone constraint-architecture predictor of productive nuclei in a system other than the one it was built for, and look for multi-fold origami data in which a fold's melting temperature rises once a neighbour has closed

## What it would do

Write a predictor that can flag supersets that lower the chance, test it
out of sample, and search the origami literature for the coupled-fold
data.

Where the record names it:

- [QUESTION-380](../questions.d/QUESTION-380.md): "tested in a system other than the one it was built for."
- [QUESTION-380](../questions.d/QUESTION-380.md): "is itself monotone in the actuator set, so it cannot flag
  the supersets that lower the chance."

## What would count

A predictor that transfers answers [QUESTION-380](../questions.d/QUESTION-380.md).

## Note of 2026-11-23: carried out by the lead run

**The predictor.** Voronoi-island coverage (VIC), the race reading of
folding islands, which can fall when a seed is added, and an alternative
(island coverage per nucleus) were pre-registered with a test system and a
criterion of transfer before any run (scratch/studies/lead-183/). The
system is a kinetic constraint-growth model in the threshold-2 regime of
the kinetic tile assembly model, not a self-folding sheet. The record of
the run is [CASE-389](../cases.d/CASE-389.md).

**The result.** Adding a target-state seed can halve the chance of exact
assembly, and island coverage beats the seed count ([CLAIM-1085](../claims.d/CLAIM-1085.md)). VIC
does not transfer ([CLAIM-1205](../claims.d/CLAIM-1205.md)). The first registered island, by static
arc consistency, was constant and the first test void; the amended one
failed on ranking and precision. A post hoc predictor, threshold-front
forcing, meets the criterion on fresh architectures ([CLAIM-1204](../claims.d/CLAIM-1204.md)), but
was built on this system, so it transfers across architectures, not
systems. Two readings are filed as alternatives: that a predictor of
productive nuclei needs the order and threshold of growth
([CLAIM-1090](../claims.d/CLAIM-1090.md), the filer's lean), and that the test system, lacking
coherent alternative branches, leaves the race reading's home case open
([CLAIM-1078](../claims.d/CLAIM-1078.md)).

**The origami search.** Arbona, Aimé and Elezgaray ([LIT-3148](../literature.d/LIT-3148.md);
[THEORY-2278](../theory.d/THEORY-2278.md)) measure a staple's melting peak rising by 1.5 to 8.5 °C
once its neighbour has folded, on a two-staple scaffold, and model ~200
staples with that coupling. No lawful open staple-resolved dataset for a
many-fold origami was found. The arXiv API returned HTTP 429 on
2026-11-23 after three queries, and was not retried, so the search was
short.

**What remains.** A test across systems of a non-monotone predictor, in a
system with coherent alternative branches (self-folding sheets, or a
lattice with two self-consistent targets sharing a region); a longer
origami search. No status or stage change.
