# THEORY-tmp6koy4: Reiter (1987) defines a diagnosis as a minimal set of components whose abnormality, with all other components normal, is consistent with a system's description and an observation; he proves that the diagnoses are exactly the minimal hitting sets of the conflict sets, that a new measurement can remove diagnoses but also create new strictly larger ones, and that the theory needs the components that might fail to be enumerated in advance. 4, Theorem 4.4, Theorem 5.7(3) and the §7 sentence on a fixed, a priori enumeration of the system components which might fail

## The account

Reiter (1987) defines a diagnosis as a minimal set of components whose
abnormality, with all other components normal, is consistent with a system's
description and an observation; he proves that the diagnoses are exactly the
minimal hitting sets of the conflict sets, that a new measurement can remove
diagnoses but also create new strictly larger ones, and that the theory needs
the components that might fail to be enumerated in advance.

4, Theorem
4.4, Theorem 5.7(3) and the §7 sentence on "a fixed, a priori enumeration of
the system components which might fail".
