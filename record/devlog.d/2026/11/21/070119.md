Merging staging into pull request 579 conflicted on three alternative
decisions, [ADR-118](../../record/decisions.d/ADR-118.md), [ADR-122](../../record/decisions.d/ADR-122.md) and [ADR-123](../../record/decisions.d/ADR-123.md). The conflicting
hunks were only the directive lines CI's repair rewrites, so the assistant
resolved them with `git checkout --ours`. That takes the whole file, not
the hunk: the branch was cut before the owner's rulings in pull request 578,
so the three went back from Rejected to Proposed. The assistant saw it on
checking the result, restored staging's versions before anything merged,
and confirmed the other files from 577 and 578 were untouched.

**What to change.** Resolve a conflict hunk by hunk, never with
`--ours` or `--theirs` on a file that the other side changed beyond the
conflict; and after any merge resolution, diff the touched files against
the side that was not kept.
