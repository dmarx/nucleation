# LIT-2253: Phase locking and multistability in the topological Kuramoto model on cell complexes

Iva Bačić, Michael T. Schaub, Jürgen Kurths and Dirk Witthaut (2026). "Phase locking and multistability in the topological Kuramoto model on cell complexes." *Nature Communications* 17: 7409. [ARXIV-2510.05831](https://arxiv.org/abs/2510.05831) DOI-10.1038/s41467-026-75565-w.

## Key takeaways

Read on 2026-11-22 ([NOTE-tmp7pvg9](../notes.d/NOTE-tmp7pvg9.md)). Generalized Kirchhoff conditions find every phase-locked state on a cell complex; coexisting stable states with nonzero winding need boundaries of five or more cells. Couplings carry no offsets, so this is the unfrustrated case of the record's cycle-consistency machinery.
