# QUESTION-tmp0eghp: Does a chat model's position along a persona axis follow the latest user message in conversations with human users not chosen by domain, and does its previous position add to the prediction once the message is known, so that a sequential model of persona position predicts held-out trajectories better than both an episode-fixed persona and independent per-turn draws?

## Why it is a question

The Assistant Axis paper (LIT-1991, NOTE-1505, THEORY-1339) shows drift in
mean trajectories over synthetic conversations, and a ridge regression in
which user-message embeddings predict a response's position (R² 0.53–0.77)
but not its change from the previous response (R² 0.10). It never
regresses position on its previous value, and its users are frontier
models given a domain and a topic. So whether persona position is set by
the latest message, carries state from turn to turn, or is fixed for an
episode is open.

## What would answer it

The test THEORY-1339's promote_when named: the drift result reproduced
with human users rather than simulated ones, in conversations not chosen
by domain: a per-turn analysis in which the latest user message predicts
the response's position along the Assistant Axis, and the previous
position does not add to it, across models; or a sequential model of
persona position (a state-space or switching model with the user message
as input) that predicts held-out trajectories better than both an
episode-fixed persona and independent per-turn draws. More simulated
conversations, or more case studies, would not settle it.

## Bearing

It bears on QUESTION-370, whose within- against between-episode test must
condition on the user's messages, and on CLAIM-536's reading of persona
selection.
