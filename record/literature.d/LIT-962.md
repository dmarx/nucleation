# LIT-962: Bisimulation Metrics are Optimal Transport Distances, and Can be Computed Efficiently

Sergio Calo, Anders Jonsson, Gergely Neu, Ludovic Schwartz and Javier Segovia-Aguas (2024), *Advances in Neural Information Processing Systems 37* (NeurIPS 2024).

Filed for [QUESTION-008](../questions.d/QUESTION-008.md): the result that bisimulation metrics are optimal-transport distances between Markov chains, with an efficient way to compute them. That is the formal object an account of approximate bisimulation would use.
