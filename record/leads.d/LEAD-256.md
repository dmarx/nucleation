# LEAD-256: Put the exchange's testbeds on one organizational state, participants, contracts, capabilities, authority, monitoring and resources, whose transition returns the organization its own activity changed, with normative evaluation kept outside the monitoring it changes, so the six experiment families extend one architecture and each compares regimes matched on ordinary performance by their divergence under perturbation of the governing relationships

## The idea

A49 proposes one state for every article's model:

| Component (A49) | "Organizational property" |
|---|---|
| P_t | "Participating processes and their dispositions" |
| C_t | "Operative relationships and contractual constraints" |
| K_t | "Maintained capabilities and reserve capacities" |
| W_t | "Authority, standing and governing relationships" |
| M_t | "Monitoring, interpretation and evaluative apparatus" |
| B_t | "Resource availability and temporal constraints" |

and one transition, T(S_t, q_t) → (a_t, τ_t, κ_t, S_{t+1}): "The important
feature is that the operation returns not only an immediate realization,
but also an organization changed by the activity required to produce it."
That feature is held: an answer benchmark misses what answering does to
the organization ([CLAIM-1156](../claims.d/CLAIM-1156.md)), and an invocation can change the
relationship it invokes, which a cost model with a fixed store misprices
([CLAIM-1319](../claims.d/CLAIM-1319.md), [ARG-246](../arguments.d/ARG-246.md)). A49 adds a constraint: "Independent
normative evaluation is then applied to the relevant history,
relationships and consequences. It should not simply be identified with
the operative evaluation apparatus M_t." The record's reason for it is
that a dropped demand scored against the system's current demands reads
as relief ([CLAIM-556](../claims.d/CLAIM-556.md)).

The method, A49's: "Match ordinary performance; perturb the governing
relationships; observe the divergence in organizational trajectories", as
in [CLAIM-364](../claims.d/CLAIM-364.md), [CLAIM-1270](../claims.d/CLAIM-1270.md) (which supersedes [CLAIM-1219](../claims.d/CLAIM-1219.md)).

A49's comparison field per investigation (control theory, transaction-cost
economics, relational contracts, cultural evolution, bargaining theory,
psychometrics and others) gives each family its baseline; the filed leads
already name most of them.

## Before it can be run

- **A common state is a claim about the leads, not a convenience.** It
  pays only if a perturbation in one family moves a quantity another
  family measures (an eroded fallback in K_t changing who can contest in
  W_t). The first run should be one such cross-family effect, against the
  same model with the components decoupled; if no cross-family effect
  appears, the shared state is bookkeeping and the leads stay separate.
- **Dynamics for each component.** A49 gives none. Capacity decay and
  rebuilding (A20 §6's update rule), contract formation by
  [CLAIM-1270](../claims.d/CLAIM-1270.md)'s probes, authority by a learned prior over governing
  processes ([CLAIM-443](../claims.d/CLAIM-443.md)) and monitoring that changes what it records
  ([CLAIM-1268](../claims.d/CLAIM-1268.md)) are the record's candidates.
- **The matching criterion and the perturbation schedule** fixed before
  any comparison, as in the record's other matched-behaviour designs
  ([CLAIM-364](../claims.d/CLAIM-364.md)).
- **The external evaluation fixed in advance**, as a reference collection
  of demands and claims the system cannot edit ([CLAIM-556](../claims.d/CLAIM-556.md)).

## What would count

A cross-family divergence predicted from the shared state and absent from
the decoupled model would show that A49's "composable parts of a common
developmental architecture" has "additional explanatory consequences of
that composition", in A49's words. Matched regimes that diverge only within
one family each would leave the leads as they are.
