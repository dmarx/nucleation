# LEAD-123: three-perspective agenda model with a latent Condorcet cycle

Builds the model CLAIM-448 names under "What would settle it": three
perspectives whose majority preferences cycle, and a chair / legibility regime
that controls which pairwise contests enter the record. Shows that the recorded
outcome (coherence, named winner, recorded conflict) is set by the admission
rule, with preferences held fixed. Generalises CASE-221 (the hand construction
of the smallest case) into a full numpy model with a legibility filter, a
protected challenge channel, and a persistence/sequential-window variant.

## Files

- `agenda_model.py` — the model and all agenda rules. `python3 -I agenda_model.py`
  writes `results.json` and prints it.
- `test_agenda_model.py` — pytest. `python3 -I -m pytest -q` (9 tests).
- `results.json` — the run (seeds fixed in `main()`; regenerated by the script).

## Rerun

## What the run shows (preferences fixed throughout)

Latent cycle: W beats R, R beats S, S beats W, each 2-1; the full contest graph
has no potential, nonintegrability 1/3.

- **Chair control.** Excluding exactly one contest makes the record acyclic.
  Excluding R-S names S, excluding R-W names R, excluding S-W names W: the chair
  can install any of the three alternatives by choosing what to leave off.
- **Agenda order.** The successive (amendment) procedure elects the
  last-introduced option; all three are reachable across the six orders.
- **Legibility filter.** Suppressing any single contest with certainty yields a
  coherent record naming a fixed winner.
- **Protected challenge channel.** Raising the suppressed contest's admission
  probability from 0 to 1 drops the fraction of coherent records 1.0 -> 0.0 and
  raises mean recorded conflict 0 -> 1/3, monotonically. CLAIM-448's prediction:
  improving legibility raises recorded disagreement.
- **Persistence.** A maintained exclusion gives one persistent recorded winner
  (TERM-078) across all 50 windows, though it is an artifact of admission;
  intermittent admission breaks coherence in some windows.
