# QUESTION-tmp3x2g4: Is knowledge of a made thing a different kind from knowledge of a given one, or the same inquiry with its answer space among realizations: does making an object give access to it, such as knowing which degrees of freedom were set and which left free, that observing it cannot?

## What makes it open

[CLAIM-tmphigw4](../claims.d/CLAIM-tmphigw4.md) holds that engineering is inquiry whose interventions make
the object they judge. One answer is that this changes only where the
answer space lies, so knowledge of a made thing is ordinary empirical
knowledge with an unusually controlled object. Another is that the maker
knows something no observer can, which degrees of freedom the specification
set and which it left to chance, and that this is a different kind: the
maker's-knowledge tradition, from Vico's verum factum, is the familiar
statement of it, and is not read here.

## What would count as an answer

A case where a maker and a careful observer of the same artifact know
different things about it that no further observation would let the
observer recover, which favours a difference in kind; or an argument that
every such difference is recoverable by observation in principle, so that
making only shortens the inquiry. Either should say what the descriptor and
imposition distinction of 2026-11-21 makes of it: a maker knows which of
the artifact's predicates were descriptors and which impositions, which an
observer sees only as a set of properties.
