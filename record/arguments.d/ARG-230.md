# ARG-230: The robust interrogation game's formula, by the linearity of expected loss in the query distribution and the minimax theorem, shows that the game is strategic only when one policy must serve several queries or the permitted query distributions are restricted

## The inference

Premise ([CLAIM-1012](../claims.d/CLAIM-1012.md), A50 §3): the game is inf over π ∈ Π(S) of sup over
ρ ∈ 𝒫(Q) of E[ℓ(q, a)], with the response conditioned on the query.
Applied results: expected loss is linear in ρ, so a sup over the whole
simplex is attained at a vertex; an infimum over a product set of
per-query choices splits into per-query infima; and von Neumann's minimax
theorem holds for a finite game in mixed strategies, where it gives the
query side an equilibrium mixed strategy. The conclusion, [CLAIM-1032](../claims.d/CLAIM-1032.md),
follows: the formula is strategic only through coupling across queries in
Π(S) or a restriction on 𝒫(Q).

## Critical questions

- **Does the formal premise hold of the setting?** It holds of A50's
  formula as written: ℓ is a loss on query and response, and the response
  law is P_π(· | q, S). A setting where the query is not seen before the
  response (a hidden test) is the preparation case of point 3, not an
  exception to it.
- **Are the theorems' conditions met?** The vertex result needs only
  linearity in ρ. The minimax theorem needs finite (or compact convex)
  strategy sets with loss linear in each player's mixture; a continuous
  query space needs a compactness condition the claim does not check, so
  its point 3 is stated for finite query families.
- **Is the application more than a relabelling?** Yes: it locates the
  game's content in the coupling of responses through the target's shared
  state, which A50's formula leaves implicit in Π(S), and connects the
  query side's "justified constraints" to a restricted 𝒫(Q). A numerical
  check on a three-query example is in [CLAIM-1032](../claims.d/CLAIM-1032.md).
