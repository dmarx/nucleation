summary: >-
  Romera-Paredes et al. (2024), Mathematical discoveries from program search
  with large language models. FunSearch pairs a frozen, pretrained code LLM
  with a programmatic evaluator in an evolutionary loop. The user supplies
  an `evaluate` function and a program skeleton; the LLM proposes new
  versions of the one function to evolve (e.g. a priority function),
  proposals are run and scored, and high scorers are kept in a programs
  database organised as islands and fed back as prompts ("best-shot
  prompting"). Applied to the cap set problem it found a 512-element cap set
  in dimension 8, larger than previously known, and improved lower bounds on
  the asymptotic capacity via admissible sets; applied to online bin packing
  it found heuristics beating first fit and best fit. Because it searches
  programs rather than solutions, outputs are short and often interpretable,
  and experts used one to find a symmetry that improved results further.
