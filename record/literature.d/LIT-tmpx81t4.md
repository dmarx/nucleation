# LIT-tmpx81t4: MIFair: A Mutual-Information Framework for Intersectionality and Multiclass Fairness

Jeanne Monnier, Thomas George, Frédéric Guyard, Christèle Tarnec and Marios
Kountouris (2026). "MIFair: A Mutual-Information Framework for
Intersectionality and Multiclass Fairness" *arXiv preprint*.
[ARXIV-2604.28030](https://arxiv.org/abs/2604.28030).

## Key takeaways

Fairness criteria for intersectional groups can be stated in
mutual-information terms; different aggregate criteria can order the same
methods differently.
