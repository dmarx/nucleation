# LEAD-249: Model a second realizer with the Northstar construction's variables, a person such as the reluctant writer, whose relations of precedence, jurisdiction, suspension and override decide which regime becomes effective, and price it against the best model of that realizer's own field by the same log-evidence test

## The gap

[CASE-325](../cases.d/CASE-325.md) (Active) modelled Northstar, an organization, by control models
alone and by a will-organization over them, and priced the difference by
log evidence ([CLAIM-174](../claims.d/CLAIM-174.md)'s test 4). [CLAIM-890](../claims.d/CLAIM-890.md) reads the result against the
fields: for an organization, institutional theory "already writes the
relations as rules-in-use", so "what is left of the explanatory-gain claim
is that one description serves across realizers, which a model of one
realizer cannot test". [CLAIM-487](../claims.d/CLAIM-487.md) is that claim. The account is "a
relabelling" only "if no second realizer shares the variables", and "The
claim leaves that open" ([CLAIM-890](../claims.d/CLAIM-890.md)).

[LEAD-141](LEAD-141.md) (Open) is [CLAIM-027](../claims.d/CLAIM-027.md)'s test for a person, an intervention that
blocks the agent model with thoughts held fixed. Its lead worker found that
"The literature does not supply" it (note of 2026-11-22). That is an
intervention on a real person; this lead is a model of one, with [CASE-325](../cases.d/CASE-325.md)'s
variables, and is not that test.

## What it would take

1. **The realizer**: the reluctant writer ([CASE-013](../cases.d/CASE-013.md), Active), whose
   endorsed commitment stays present "while email and minor tasks win",
   and who later "installs a precommitment device that removes the
   tempting option"; its note of 2026-10-13 adds A5's mechanism, an
   avoidance coalition working "on the conditions of influence". The
   case's own audit note says jurisdiction "has only institutional
   examples", so the model must give the person one.
2. **The variables**: precedence, jurisdiction and suspension ([TERM-017](../terms.d/TERM-017.md)),
   with override, composed as in [CASE-325](../cases.d/CASE-325.md), over the person's regimes
   (the commitment, the avoidance coalition, the precommitment device).
3. **The field's own model** as the rival: expected value of control
   ([THEORY-1110](../theory.d/THEORY-1110.md)) and a planning model with the plan held fixed, the models
   [CLAIM-890](../claims.d/CLAIM-890.md) sets beside [CASE-325](../cases.d/CASE-325.md), written for the person.
4. **The test**: the same log-evidence comparison, with Occam cost, on
   episodes generated from the stipulated case, and the held-out
   combinations of changes of authority that [CASE-325](../cases.d/CASE-325.md)'s gain turned on
   ([CLAIM-889](../claims.d/CLAIM-889.md)).

## What would count

- **For [CLAIM-487](../claims.d/CLAIM-487.md)**: the same will-organization variables beat the
  person's field models by more than their Occam cost and predict combined
  changes of authority the field models cannot, so one description serves
  two realizers.
- **Against it**: the person's field already writes the relations (as
  institutional theory does for an organization), or the variables have to
  be changed to fit the person, so that the "one description" is two.
- **The limit**: a stipulated person, as [CASE-325](../cases.d/CASE-325.md)'s is a stipulated
  organization. A model shows the description can serve; whether it does
  for real persons is [LEAD-141](LEAD-141.md)'s intervention.
