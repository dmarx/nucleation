## Ideas of the source (ledger) and their disposition

- **C1.** The mapping: T(v,h) = −E(v,h) + H(v) (eq. 18) makes variational
  RG's coarse-grained Hamiltonian equal to the RBM's hidden-unit
  Hamiltonian (eqs. 19–21). Disposition: **file in the NOTE and a
  THEORY** (the paper's main result).
- **C2.** Exact RG (Tr_h e^T = 1) corresponds to the RBM reproducing the
  data exactly (KL = 0), and T is then exactly the conditional
  log-probability (eq. 22). **THEORY** (same as C1, second part).
- **C3.** The two schemes use different variational criteria: free-energy
  difference (RG) versus KL divergence (ML); the paper states this but
  still calls the mapping "exact". **NOTE**, and a gap (G1).
- **C4.** The correspondence holds for any Boltzmann machine, not only
  RBMs (it does not use E's form). **NOTE.**
- **C5.** 1D Ising: decimation as a deep architecture with couplings
  tanh J(n+1) = tanh² J(n), flowing to the stable fixed point J = 0; the
  architecture keeps no information about the decimated half of the
  visible spins. **NOTE.**
- **C6.** 2D Ising at J = 0.408: a four-layer stacked RBM (1600–400–100–25)
  with L1 penalty learns local blocks whose receptive fields grow with
  depth, "self-organizing to implement block spin renormalization";
  reconstructions keep macroscopic features at compression 64. **NOTE
  and THEORY** (the empirical half of the paper's thesis).
- **C7.** The thesis: deep learning "may be implementing a generalized
  RG-like scheme". **THEORY** (Proposed), qualified by R1.
- **C8.** Discussion: universality and fixed points as machinery that
  might be imported; obstacle, RG is applied to systems with many
  symmetries and DL data has limited structure. **NOTE** (passing; left
  as no content of its own beyond C7).
- **C9.** Tensor networks / disentanglers and variational RG as a possible
  import; and DL as a route to better real-space RG. **Left**:
  speculative, no content of its own.

## Gaps in the source's own argument

- **G1.** "Exact" is definitional: eq. 18 defines T from E and the data
  Hamiltonian H, which is unknown for real data; and the learning
  criteria differ (C3). The exactness is a reparameterisation of a joint
  energy, not a claim that RBM training performs RG. This is where
  THEORY-194's objection bites.
- **G2.** Eq. 8 states ΔF = 0 ⇔ Tr_h e^T = 1. The per-configuration
  condition implies ΔF = 0, but ΔF = 0 alone (one scalar) does not imply
  it for every v; the "⇔" is overstated.
- **G3.** The 2D Ising critical coupling is given as J/(k_B T) = 0.4352;
  Onsager's exact value is ln(1+√2)/2 ≈ 0.4407. The paper's number does
  not check. (J = 0.408 is still on the disordered side either way.)
- **G4.** Sample count: 20,000 samples in the main text, 40,000 in
  Appendix A.
- **G5.** No control for the L1 penalty: sparsity alone may produce local
  receptive fields; the block structure is not shown to be RG-specific
  (no comparison with a shuffled or non-critical ensemble, no check of
  flowing couplings in 2D).
- **G6.** The 1D construction is hand-built, not learned, so it shows the
  architecture can express decimation, not that training finds it.
