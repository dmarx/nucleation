## Citing this work

If an idea here is useful to your own work, please cite it. GitHub's "Cite
this repository" button, generated from `CITATION.cff`, gives the record
in APA and BibTeX. To cite the record as a whole:

```bibtex
@misc{marx2026nucleation,
  author       = {Marx, David},
  title        = {Nucleation: A Record of an Ongoing Philosophical Inquiry},
  year         = {2026},
  howpublished = {\url{https://github.com/dmarx/nucleation}},
  note         = {Published at \url{https://dmarx.github.io/nucleation/}}
}
```

To cite a single idea, cite its entry by code, and pin the version you read
with a commit permalink, since entries are revised in place:

```bibtex
@misc{marx2026nucleation-claim039,
  author       = {Marx, David},
  title        = {{CLAIM-039}: Organized systems can have affective states},
  year         = {2026},
  howpublished = {Nucleation, \url{https://github.com/dmarx/nucleation/blob/<commit>/record/claims.d/CLAIM-039.md}},
  note         = {Status: Proposed, as of commit <commit>; accessed <date>}
}
```

A few things to know when citing an entry:

- **Cite a numbered code** (`CLAIM-039`), not a temporary one
  (`CLAIM-tmp…`). Temporary codes are assigned when an entry is filed and
  are replaced by numbers when the entry reaches `main`.
- **Give its status.** An `Active` entry is what the record currently
  holds. A `Proposed` one is an open position the record has not adopted.
  Citing a `Proposed` claim as settled misreports it.
- **Check who an idea belongs to.** Much of the record is drafted with AI
  assistance. Each entry's summary says whose idea it is (the owner's, or
  an assistant's, and in whose wording) and which exchange it came from.
  Readings of other people's work (`LIT`, `NOTE`, `THEORY` entries) should
  be cited to those authors, not to this record.
