# THEORY-tmpzmf41: Majumder et al. (2024) report that on DiscoveryBench, 264 tasks derived from published data-driven studies in six domains plus 903 synthetic tasks, in which an agent must state a hypothesis (context, variables and relationship) supported by a given dataset, the best LLM-based discovery agent scored about 25%, reasoning and self-critique scaffolds did not beat a simple code-generation agent, and performance fell as the required analysis workflow lengthened.

## The account

Majumder et al. (2024) report that on DiscoveryBench, 264 tasks derived from published data-driven studies in six domains plus 903 synthetic tasks, in which an agent must state a hypothesis (context, variables and relationship) supported by a given dataset, the best LLM-based discovery agent scored about 25%, reasoning and self-critique scaffolds did not beat a simple code-generation agent, and performance fell as the required analysis workflow lengthened.
