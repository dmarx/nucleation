**Held, with dated notes: 15 of the 16 flagged entries.**

- In most of them what had moved was bookkeeping: a converse edge, a
  dropped unread ground, a directive.
- Where it was real, it did not end the wait. [CLAIM-143](../../record/claims.d/CLAIM-143.md) going Active, for
  example, firms [CLAIM-471](../../record/claims.d/CLAIM-471.md)'s standard and supplies no case.

**The flag needs a note to clear.** The first instruction to reviewers,
draft no new note unless the old one was wrong, would have left all fifteen
on the list every pass. The flag compares against the latest note's date,
so only a dated note clears it. A dated note is also the record that the
review happened, which is what the timer guarantees. The README now says
so: when the wait stands, append a dated note restating it and naming the
move checked, and replace the old note only where it is wrong. Two entries
raised by the pass's own revisions, [CLAIM-286](../../record/claims.d/CLAIM-286.md) and [THEORY-662](../../record/theory.d/THEORY-662.md), were
rechecked the same way, and the list ends empty.
