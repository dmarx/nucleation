# LEAD-tmpv7rgf: Estimate per-step kernels from several independent retellers per generation on held-out and perturbed inputs, in a metric fixed beforehand, and predict end-to-end drift

## What it would do

Fix the metric and assign conditions to regimes, then estimate kernels and
predict drift with an interval tested on other chains; record
per-generation judgements of communicative configuration.

Where the record names it:

- CLAIM-208: "A design that estimates each step's kernel from several
  independent retellers on held-out inputs and perturbed inputs at each
  generation."
- CLAIM-059: "no metric is fixed and no condition is assigned, so the test
  it names has nothing yet to test."

## What would count

Drift predicted within interval supports the compositional half of the
line's success criterion.
