# LIT-1170: Measuring Autonomy and Emergence via Granger Causality

Anil K. Seth (2010), "Measuring Autonomy and Emergence via Granger Causality", *Artificial Life* 16(2): 179–196 — doi:10.1162/artl.2010.16.2.16204

## Key takeaways

*From the reading, [NOTE-935](../notes.d/NOTE-935.md).*

- **G-autonomy (Eq. 3).** ga_{X1|X2} = log(var(ε₁ without X1's own
  lags)/var(ε₁ full)): how much a variable's own past improves its
  prediction once external variables are in the model. A white-noise
  variable and a variable driven only by white noise both score zero.
- **G-emergence (Eq. 4).** ge_{M|m} = ga_{M|m} · (1/N)Σ gc_{mᵢ→M}: a
  macro variable is emergent from micro variables to the extent that it
  is both G-autonomous from them and G-caused by them. Nonlinear versions
  use Taylor-expanded regressors (Eqs. 5–6).
- **Validations.** An evolved predator controller has higher G-autonomy
  than a rule that also uses internal state, which beats a pure pursuit
  rule (§3.2). In boids, the hand-chosen flocking condition has higher
  G-emergence of the centre of mass than random or rigid motion, and
  higher Granger causality from the centre of mass to each boid (§4).
- **What it is relative to.** G-emergence can be positive because micro
  causal factors are missing from the model, or because the macro
  variable is easier for the prediction algorithm; with the system itself
  as predictor it would be zero (§5.2). Downward causation is called
  "ontologically innocent": Granger causation from macro to micro (§4.2).
