# THEORY-tmphkpxr: None recommended: the work is a programme statement with no findings

## The account

None recommended: the work is a programme statement with no findings. If one is wanted: DARPA's
SAIL-ON programme (2019) framed open-world novelty for AI as four successive capabilities,
recognising that the world has changed, characterising the change, adapting the response and
updating the world model, and required evaluation on generated novelty graded in a hierarchy.
