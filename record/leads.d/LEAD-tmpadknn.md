# LEAD-tmpadknn: Test whether acquired organization changes which probes a learner can afford or chooses to make: random, uncertainty, information-gain, expected-free-energy and cost-aware probe selection after the environment changes, with a forced-probe condition separating inquiry failure from inference failure

## What it would do

After a learner has a strong model, change the environment so the model
is incomplete; compare probe-selection policies; give a locked-in learner
the corrective evidence it would not seek. If it updates, the failure was
in inquiry; if not, in inference or plasticity.

## What is not yet settled

A task-composition setting, found in prior work or built ([LEAD-tmphfbq0](LEAD-tmphfbq0.md)), the probe costs, and what counts as two learners
with the same present competence.
