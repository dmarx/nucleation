# LIT-248: Self-Supervised Learning with Kernel Dependence Maximization

Yazhe Li, Roman Pogodin, Danica J. Sutherland, Arthur Gretton (2021), *Advances in Neural Information Processing Systems 34 (NeurIPS 2021); first appeared as arXiv preprint* — [ARXIV-2106.08320](https://arxiv.org/abs/2106.08320)

## Key takeaways

*From the reading, [NOTE-tmp9jxqd](../notes.d/NOTE-tmp9jxqd.md).*

- **HSIC with identity labels.** On N equally likely images with one-hot
  labels and a label kernel Δl·1[y = y′] + l₀,
  HSIC(Z,Y) = (Δl/N)·(E_pos k(Z,Z′) − E k(Z,Z′)) (Theorem A.1). The label
  kernel enters only as a prefactor.
- **The MMD form.** With μ_i the mean embedding of image i's view
  distribution, (1/2N²)Σ_ij MMD²(i,j) = (N/Δl)·HSIC(Z,Y) (App. B.2), an
  exact derivation with no stated integrability condition. It needs the
  mean embeddings to exist, which holds for the bounded kernels used.
- **InfoNCE, exactly.** In its large-batch form, L_InfoNCE = −HSIC(Z,Y) +
  E_Z log E_Z′ exp(k − μ₁) (eq. 28), an identity.
- **InfoNCE, bounded.** For |k| ≤ k_max, Theorem B.1 bounds
  −HSIC(Z,Y) + γHSIC(Z,Z) by L_InfoNCE plus a remainder of second order in
  Var_Z′ k. The printed theorem gives the remainder a minus sign; its own
  proof step gives a plus. With the cosine critic at τ = 0.1, γ = 0.0475.
  The small-variance Taylor form (eq. 7) is the approximation the main
  text leads with.
- **Clustering.** With linear kernels and centred unit-norm features,
  −HSIC(Z,Y) is within-image scatter, a k-means objective (eq. 10).
  BYOL's loss is read as its two-view case, which depends on the centring
  assumption.
- **Estimation.** The i.i.d. HSIC estimator is biased for SSL batches. An
  unbiased one (Theorem A.2) and an O(1/B)-biased one (eq. 17) are given,
  with random Fourier features for an inverse multiquadric kernel
  (Theorem C.1).
- **Results.** 74.8% ImageNet top-1 linear evaluation with a target
  network, 72.2% without. Single runs.
