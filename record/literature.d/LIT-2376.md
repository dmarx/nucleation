# LIT-2376: How to detect information voids using longitudinal data from social media and web searches

Irene Scalco, Francesco Gesualdo, Roy Cerqueti and Matteo Cinelli (2026). "How to detect information voids using longitudinal data from social media and web searches." *Scientific Reports*. DOI-10.1038/s41598-026-69786-8.

## Key takeaways

Read on 2026-11-12 ([NOTE-1748](../notes.d/NOTE-1748.md)). An operational, replicable definition
and detector for "information voids" as anomalous demand–supply imbalances,
plus an associational link between voids and lower average source
credibility.
