# LIT-928: Sparse Distributed Memory

Pentti Kanerva (1988), *Sparse Distributed Memory*, MIT Press, Cambridge MA

## Key takeaways

*Filed, not read.* Known here by what it is standardly cited for.

- Addresses are patterns. A memory is written to, and read from, the hard
  locations near its own content, so the content is the address.
- A noisy cue retrieves a stored pattern by iterated reading only if it
  lies within a critical distance of it. Beyond that, reading does not
  converge on the pattern.
- Kanerva maps the model onto the cerebellum.
