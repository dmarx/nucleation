# LIT-tmporx78: Introducing a predictive-oriented multi-stakeholder recommender system model

Reza Davoudabadi, Ahmad Makui and Mohammad R. Rasouli (2026). "Introducing a predictive-oriented multi-stakeholder recommender system model." *Scientific Reports 16(1)*. DOI-10.1038/s41598-026-37793-4.

## Key takeaways

Read on 2026-11-12 ([NOTE-tmp64zjh](../notes.d/NOTE-tmp64zjh.md)). A scoring scheme in which an
organization's operational state, and both parties' "flexibility", set the
trade-off between user preference and organizational need, intended to steer
demand toward items the organization can supply.
