# QUESTION-096: When does a communicative cue change what an interpreter can recover from an unchanged internal state, and how can such an addressing effect be told apart from new information, added computation or a changed policy?

## Why it is a question

A19 §2: "Information can be stored perfectly well while the current cue
fails to activate it." That a cue exists that retrieves x does not imply
the cue now given does. A19 §5 tabled what each intervention changes: a
better cue changes access, a better decoder changes extraction,
added context changes the information, more compute changes the
resources, a better policy changes action. "Identical improvements in task
accuracy could arise through any of these routes."

A19 placed it in the pragmatic-transport line: "communication changes not
only what information a receiver is given, but the addressing conditions
under which existing information becomes recoverable." [CLAIM-298](../claims.d/CLAIM-298.md) states
that as a thesis.

The record holds the mechanism A19 reached for and did not cite: [LIT-269](../literature.d/LIT-269.md)
(Bricken and Pehlevan, read), with SDM itself ([LIT-921](../literature.d/LIT-921.md), read; [LIT-928](../literature.d/LIT-928.md),
Unavailable) and [THEORY-261](../theory.d/THEORY-261.md) on SDM recall. An answer is a design that
holds the memory fixed, varies the cue, and measures retrieval and
judgement separately, as A20 §5 proposed.
