# LEAD-tmpxig9c: Find or run a transmission chain whose endpoint is compared with a prior measured on its own transmitters before transmission, and chains started from different stances

## What it would do

Search the iterated-learning literature first; failing a study, run chains
with the transmitters' prior measured beforehand.

Where the record names it:

- [CLAIM-090](../claims.d/CLAIM-090.md): "waits on a chain whose endpoint matches a prior measured on
  its own transmitters before transmission"
- [CLAIM-068](../claims.d/CLAIM-068.md): "Its defeat condition asks for chains started from different
  stances, and no such study is held."

## What would count

An endpoint that matches the measured prior supports [CLAIM-090](../claims.d/CLAIM-090.md); one that
does not defeats it.
