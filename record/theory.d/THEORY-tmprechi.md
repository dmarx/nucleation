# THEORY-tmprechi: Caliari and Petri argue that aggregate choice data consistent with random utility maximization can, exactly when the population's preferences are sufficiently uncorrelated, be generated by decision-makers none of whom maximizes a preference, so that individual rationality and the welfare judgments built on it cannot be read off aggregate choices without the analyst's prior assumptions.

## The account

Caliari and Petri argue that aggregate choice data consistent with random utility maximization can, exactly when the population's preferences are sufficiently uncorrelated, be generated by decision-makers none of whom maximizes a preference, so that individual rationality and the welfare judgments built on it cannot be read off aggregate choices without the analyst's prior assumptions.
