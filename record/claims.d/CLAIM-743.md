# CLAIM-743: A demand owed to a party can cease to apply legitimately only by the exercise of a valid normative power over it, the holder's release or waiver or an authorized revision, which changes the reference set against which relief is judged; an institution's ceasing to count it changes only the set it recognizes, so what separates a valid release from suppression is whether a valid power was exercised, and by whom

## The claim

A97 X of the exchange "Assess Depp Heard Abuse"
(https://chatgpt.com/share/6afcb46d-83a8-83e9-9c85-4a0c3604405b), on when
an institution may change its commitments:

| Transformation | What changes | Normative question |
|---|---|---|
| **Better realization** | New capabilities make existing requirements jointly satisfiable | Does the reform genuinely meet the original demands? |
| **Policy revision** | The institution changes how it pursues valid obligations | Is the new policy appropriately authorized and effective? |
| **Valid normative modification** | A legitimate power changes an obligation or entitlement | Did the actor possess authority to make the change? |
| **Illegitimate suppression** | The institution ceases to recognize a claim that remains valid | Has it merely hidden an unsatisfied obligation? |

"A demand can legitimately cease to apply. For example, B may validly
release A from a contractual obligation. That release can alter the
rights and obligations themselves. It would be mistaken to classify every
removal of a demand as suppression. But an institution cannot achieve the
same effect merely by ceasing to count the obligation."

> **The difference is whether a valid normative power was exercised.**

"A valid waiver changes the reference normative relationship. An
unauthorized deletion changes only the institution's representation or
policy." With N_t the applicable standard and N̂_t the institution's
recognized one, a valid normative act moves N_t → N_{t+1}; institutional
deletion moves N̂_t → N̂_{t+1}, and "The second transformation does not
establish that the independently applicable obligations in \(N_t\) have
changed."

The claim: for a demand owed to a party (not one the organization merely
maintains for itself), the reference set may change only by a valid
power, and then it does change; otherwise only the recognized set
changes. Who holds the power is part of the test: the holder can release,
an authorized body can revise, the obligated institution cannot delete.

## How it sits with the record

- **[CLAIM-361](CLAIM-361.md)** (Active), which this rests on: relief is judged against a
  fixed reference set D₀, and "a demand excised or suppressed has changed
  the comparison and has not been satisfied". It keeps a correspondence
  between earlier and later demands recording whether each was
  "fulfilled, transferred, revised, suppressed, or abandoned". It does
  not say what licenses changing D₀. This claim supplies the license for
  demands owed to others, and leaves [CLAIM-361](CLAIM-361.md)'s constitutive revision of
  an organization's own demands where it is.
- **[CLAIM-662](CLAIM-662.md)** (Proposed) and A97 IV's D_recognized against
  D_warranted,N: the recognized set can move without the warranted one.
  This claim says how the warranted one moves.
- **[QUESTION-456](../questions.d/QUESTION-456.md)** asks how the demand set is established defensibly when
  the organization's governance shapes it. This claim answers one part:
  removals are defensible when made by a valid power, held by the right
  party.
- **[CLAIM-738](CLAIM-738.md)**: a passage between rights, demands and commitments
  needs its own warrant. A release is one such passage.
- **[CLAIM-722](CLAIM-722.md)**: a claim persists through the loss of its remedy.
  Release is how it can end; making the remedy unreachable is not.

## What it does not say

- Not which powers are valid. Some rights may not be releasable at all
  ([CLAIM-720](CLAIM-720.md)'s nonwaivability).
- Not that an institution may never revise. "Policy revision" changes how
  valid obligations are pursued and needs only authorization; A97 V's
  point that fidelity can require revising a rule belongs there.
- Not that a release obtained under pressure is valid. Validity is the
  standard's question, and [CLAIM-722](CLAIM-722.md)'s part 3 bears on releases
  obtained through the violation.
