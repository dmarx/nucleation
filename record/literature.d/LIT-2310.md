summary: >-
  Chi et al. (2026), AI4AI-Bench: Benchmarking LLM Agents in Algorithmic
  Design for Recursive Self-Improvement. The paper argues that recursive
  self-improvement compounds mainly through the "algorithmic design level"
  (objectives, update rules, regularization, schedules), as opposed to
  systems engineering or data, and builds a benchmark that isolates it: ten
  frozen research repositories covering ten families of training algorithm.
  An agent gets 4 hours on one B300 GPU and a cheap proxy metric to rewrite
  the repository's training algorithm; its source code alone is then rerun
  from scratch for up to 12 hours and scored by an evaluator fixed in
  advance and hidden from it, against the repository's own algorithm run
  identically. Scores map each metric onto one scale (0 uninformative, 0.1
  the shipped algorithm, 1.0 the optimum). A separate language model
  classifies each diff by whether it changes "how this run goes" (budget,
  hyperparameters, checkpoints, capacity) or "how the model learns" (loss,
  supervision, update rule, data). Read for the exchange "luria experiment
  design".
