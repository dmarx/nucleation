# THEORY-tmpx361j: Tomasello holds that agency is an organization of perception, goals and decision for acting where the environment is unpredictable, that learning serves it as a subprocess, that current machines lack its executive tier and the shared intentionality from which humans create conventions, so that artificial agents are better built up from coordination than down from language, and that markets and other emergent social regularities are not agents

## The account

Nature builds behaviour in where the environment is predictable and builds
a decision-making agent where it is not, other agents being the least
predictable part. Agency is a kind of organization, as life is, not a
substance; learning exists to serve decisions. Machines have the basic
loop but not the executive tier that monitors and plans, nor the shared
agency in which humans create conventions; language models start from
language, the endpoint, so agents should be built from coordination up.
Markets, traffic jams and inflation emerge from individuals' intentions
without being agents.

## Evidence

An interview; restates the agency book and Tomasello's earlier work, with
opinions on AI.
