# THEORY-tmpn7ukf: De Kleer (1986) proposes that a truth maintenance system label each datum with the minimal sets of assumptions from which the recorded justifications derive it, so that the database need not be consistent, contradictions only mark assumption sets as inconsistent, rival contexts can be examined together, and retraction is done by contradicting an assumption rather than deleting a justification

## The account

De Kleer (1986) proposes that a truth maintenance system label each datum
with the minimal sets of assumptions from which the recorded justifications derive it,
so that the database need not be consistent, contradictions only mark assumption sets as
inconsistent, rival contexts can be examined together, and retraction is done by
contradicting an assumption rather than deleting a justification.
