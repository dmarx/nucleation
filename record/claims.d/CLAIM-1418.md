# CLAIM-1418: Unconscious access is the same content in a format flexible consumers cannot read

## The claim

Three held results fit together.

- **The same content, used two ways.** [NOTE-1069](../notes.d/NOTE-1069.md) reads Gurnee, Sofroniew
  et al. ([THEORY-865](../theory.d/THEORY-865.md), Active) as finding that the information a model uses
  for continuation, anomaly detection and line wrapping is the same
  information it reports, held in a different place. "Notably, in all cases
  ... the same underlying information is available to the model and used
  for task computations" (p. 24). Computations "appear to route through the
  J-space only in the context of explicit report and flexible inference"
  (p. 24). "The model can thus represent and use a property without that
  property's label entering the J-space" (p. 79). The authors allow that
  one "could consider J-space-independence as an operational definition of
  automaticity in a language model" (p. 21). [NOTE-1069](../notes.d/NOTE-1069.md)'s own summary: "a
  difference in format, not in content".
- **Content measures are blind to format.** [THEORY-227](../theory.d/THEORY-227.md) (Active): mutual
  information between an input and its representation "does not fix the
  representation's quality", since invertible encoders all preserve it
  exactly while differing under a linear probe. Any recoding-invariant
  measure of information content therefore gives the J-space component and
  a J-orthogonal recoding of the same content the same value.
- **Access is consumer-relative.** [CLAIM-003](CLAIM-003.md) says a workspace need not give
  every subsystem the same access. [CLAIM-349](CLAIM-349.md) separates access to a signal
  from its authority over action, and from action on it. In the J-space
  results the line-wrapping consumer reads the width outside the workspace
  and acts on it. The report consumer reads it only once it is loaded.

Together: "unconscious access", as in blindsight or masked priming
([CLAIM-411](CLAIM-411.md)'s standard cases), is access without access consciousness. The content is
present and causally effective. What is missing is that it is in the
format the flexible consumers read. Access consciousness is then a relation, a format
together with the consumers able to read it, and not a quantity of
information. [THEORY-454](../theory.d/THEORY-454.md)'s "cognitive envelope", in which percepts are put
to cognitive use only once recoded, is the same structure in perception.

## What it buys

- **For [CLAIM-411](CLAIM-411.md).** The further organizational property [CLAIM-411](CLAIM-411.md) asks
  the constitutive thesis to name has a candidate that is independent of
  report: being in a format that a set of flexible consumers can read. It
  can be measured by swaps, as the J-space is, and not by report. Whether
  that property makes an interpretation experiential is not settled here.
- **For [CLAIM-439](CLAIM-439.md).** "Available to the system's other processes" can be
  given an operational sense: the content is in a format those processes
  read. Unfelt valence would be valence used outside it.
- **For [QUESTION-061](../questions.d/QUESTION-061.md).** Access is not one broadcast. It is graded by
  consumer, in the model at least.

## What it does not say

- That the J-space is consciousness, or that access is experience. [THEORY-1226](../theory.d/THEORY-1226.md)
  and the authors take no position on phenomenal consciousness.
- That recoding is free or always possible.
- That information content plays no part. It is necessary for use; it is
  only not what separates access-conscious from unconscious use.

[LEAD-290](../leads.d/LEAD-290.md) proposes the test of the content half.
