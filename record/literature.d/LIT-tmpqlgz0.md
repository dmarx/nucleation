# LIT-tmpqlgz0: gIBIS: a hypertext tool for exploratory policy discussion

Jeff Conklin and Michael L. Begeman (1988), *ACM Transactions on Information Systems* 6(4):303–331 — DOI-10.1145/58566.59297

## Key takeaways

*Registered, not read.* From the abstract only: gIBIS is a hypertext system
built to capture early design deliberations by the IBIS method of
[LIT-tmpf7m81](LIT-tmpf7m81.md), for large and complex design problems. It uses colour and a
relational database server so that team members across a local network can
build and browse typed IBIS networks together. The authors report that early
experiments suggest the IBIS method is still incomplete, but that tool and
method match well.
