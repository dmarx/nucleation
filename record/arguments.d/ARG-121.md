# ARG-121: Slow register, archive → two kinds of separation

## The inference

1. [CASE-116](../cases.d/CASE-116.md)'s arm A is a slow flip register, second eigenvalue 0.98, that
   no member reads. It has a slow collective variable: dynamical
   separation.
2. No process uses arm A's register, so nothing that would otherwise be
   computed is replaced by it: no economic separation.
3. Arm C passes a rule through an archive between two episodes that never
   run together. The second episode applies the rule without forming it
   again: costly formation once, cheap use later, an economic
   separation.
4. Arm C has no continuous dynamics across the gap, so the rule is not
   the attractor or slow variable of any process: no dynamical
   separation.
5. So each separation occurs without the other.

## Critical questions

**Is the case coherent?** Yes. [CASE-116](../cases.d/CASE-116.md) is a finite-state construction
whose eigenvalues and intervention effects were rechecked when it was
filed. It is fictional by construction, which an existence proof allows.

**Does it separate the very things the conclusion says come apart?** For
arm A, yes: slowness is computed and no reader exists. For arm C, partly.
The case was built to separate transmission from continuous operation,
not to price formation against use, so that the archived rule saves the
second episode work is implied by "a rule passed through an archive"
rather than computed in the case. A version of arm C with a stated cost
of forming the rule would remove the qualification.
