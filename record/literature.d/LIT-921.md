# LIT-921: Sparse Distributed Memory and Related Models

Pentti Kanerva (1992), RIACS Technical Report 92.10, NASA Ames; published 1993 in M. H. Hassoun (ed.), *Associative Neural Memories*, Oxford University Press

## Key takeaways

*From the reading, [NOTE-779](../notes.d/NOTE-779.md).*

- **Two matrices.** A fixed random address matrix A selects the hard
  locations within a radius of the cue; a contents matrix C of counters
  is trained by the outer-product rule, C := C + y(Ax) ⊗ w, and read by
  z = sign(Cᵀy(Ax)).
- **A RAM is the special case.** With all 2ᴺ addresses, radius zero and
  one-bit counters, the memory returns exactly the word last written at
  an exact address.
- **Expansion buys capacity.** Addressing through A turns an N-bit cue
  into an M-dimensional, nearly orthogonal activation vector, which makes
  capacity "independent of the input dimension N".
- **Signal and noise.** For uniform random data and an exact cue, a bit's
  sum has mean pM and variance pM[1 + pT(1 + p²M)]; fidelity is Φ of
  their ratio, best at p = (2MT)^−1/3.
- **Capacity.** It tends to 1/[Φ⁻¹(φ)]² of the hard locations: 0.105 at
  φ = 0.999 (0.096 for a million locations). Keeler's result, cited, gives
  the Hopfield net the same capacity per storage element. In practice,
  store 1–5% of M.
- **Not analysed here.** Noisy cues, which lower capacity (Chou 1989),
  and the critical distance of iterated reads, which is only illustrated.
- **Names and patterns.** A name is "an ideal encoding, except that it is
  arbitrary"; in pattern computing the units "serve both as pointers and
  as data, and they need not be precise".
