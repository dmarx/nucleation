# THEORY-tmph4vkf: Herrmannsdoerfer, Benz and Juergens propose that a modeling language be evolved as a recorded sequence of coupled transactions, each pairing a metamodel adaptation with the migration of existing models — reusable library operations for recurring changes, custom ones for metamodel-specific changes — from which a migrator can be generated, and report that in the reconstructed histories of the GMF and PCM metamodels nearly all coupled changes were covered by reusable operations, with only a handful of custom migrations needed. `

## The account

Herrmannsdoerfer, Benz and Juergens propose that a modeling language be evolved as a recorded sequence of coupled transactions, each pairing a metamodel adaptation with the migration of existing models — reusable library operations for recurring changes, custom ones for metamodel-specific changes — from which a migrator can be generated, and report that in the reconstructed histories of the GMF and PCM metamodels nearly all coupled changes were covered by reusable operations, with only a handful of custom migrations needed.
