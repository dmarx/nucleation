# LEAD-140: Compare an earlier and a later improver of a record-keeping collective from the same fresh state at the same budget, then damage its diagnostic machinery

## What it would do

Run [CASE-255](../cases.d/CASE-255.md), which adapts [CASE-186](../cases.d/CASE-186.md): let a collective improve its
procedures over generations, transplant an earlier and a later improver
onto the same fresh state at equal budget, then damage the diagnostic
machinery.

Where the record names it:

- [QUESTION-457](../questions.d/QUESTION-457.md): "A study in which a collective improves its procedures
  over generations, an earlier and a later improvement procedure are each
  applied to the same fresh starting state at the same budget, and the
  collective's diagnostic machinery is then damaged"
- [QUESTION-388](../questions.d/QUESTION-388.md): "a governing rule's change must alter behaviour under
  controlled later tasks"

## What would count

The later improver doing better from the same start, and losing that
advantage when diagnosis is damaged, answers [QUESTION-457](../questions.d/QUESTION-457.md) for the
collective; [QUESTION-457](../questions.d/QUESTION-457.md) itself warns that it does not establish
independent self-governance.
