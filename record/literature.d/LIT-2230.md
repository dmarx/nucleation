# LIT-2230: Optimal phase-selective entrainment of electrochemical oscillators with different phase response curves

Jorge Luis Ocampo-Espindola, Bharat Singhal, Jr-Shin Li and István Z. Kiss (2024). "Optimal phase-selective entrainment of electrochemical oscillators with different phase response curves." *Chaos* 34(7): 073129. DOI-10.1063/5.0205480.

## Key takeaways

Read on 2026-11-22 (NOTE-tmp5rss0). A one-way, open-loop common drive designed from the units' phase responses imposes a chosen synchrony pattern, clusters included, on oscillators not coupled to each other. A's description is borne out.
