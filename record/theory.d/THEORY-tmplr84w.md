# THEORY-tmplr84w: Wang and colleagues report that on 784 expert-curated questions requiring tool use across several AI papers, the best LLM agent configuration (Gemini 2.5 Pro in a manager–worker workflow) averages 38.78% accuracy, 18.47% on hard questions, against 83.5% for a Ph.D. expert, with agents overusing general-purpose tools and planning far from the minimal tool chain.

## The account

Wang and colleagues report that on 784 expert-curated questions requiring tool use across several
AI papers, the best LLM agent configuration (Gemini 2.5 Pro in a manager–worker workflow) averages
38.78% accuracy, 18.47% on hard questions, against 83.5% for a Ph.D. expert, with agents overusing
general-purpose tools and planning far from the minimal tool chain.
