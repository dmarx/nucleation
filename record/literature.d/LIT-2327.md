  Zhang, Hu, Lu, Lange and Clune (2025), Darwin Godel Machine: Open-Ended
  Evolution of Self-Improving Agents. The DGM is a coding agent that
  improves itself by editing its own code repository and keeps every viable
  variant in an archive. Each iteration picks a parent from the archive
  (weighted toward high scorers with few children), has it read its own
  benchmark logs, propose a feature and implement it in its own code; the
  child is evaluated on coding benchmarks (SWE-bench Verified subset,
  Polyglot) and archived if it can still edit code. Because
  self-modification is itself a coding task, better coding scores are taken
  as better self-improvement ability. Over 80 iterations the DGM raises
  SWE-bench from 20.0% to 50.0% and Polyglot from 14.2% to 30.7%, beating
  ablations without self-improvement (fixed meta-agent) and without the
