# CLAIM-tmp97pg4: Luria did not originate in Nucleation: it was extracted from the process the owner used to steer an LLM pair-programming collaboration on a webapp, and Nucleation is the first project outside that webapp and luria itself governed by it, which makes Nucleation evidence that luria is a reusable library and not an application's core split off

## The claim

The owner, at U14: "luria evolved from the process I was using to steer a pair programming collaboration with an LLM to develop a webapp. I encapsulated that process in luria to  facilitate reproducing that process, and Nucleation is the first thing outside of that webapp and luria itself to be developed via luria's governance."

Two things are said. A history: the governance process came first, in a
software collaboration; luria is its extraction; Nucleation is its first
use outside the webapp and luria. And an inference: because Nucleation is
not where luria came from, Nucleation's being governed by it is evidence
that the extraction found a reusable abstraction, "not just unnecessarily
modularized core that isn't actually reusable". A library used only by the
project it was split from cannot show that; a second project of a different
kind can.

## What it does not say

- Not that luria needed no change to govern Nucleation. [CLAIM-tmp5fv9h](CLAIM-tmp5fv9h.md)
  finds that it needed many, and reads what kind they were.
- Not that one second project establishes generality for every kind of
  inquiry; [CLAIM-tmpmnjir](CLAIM-tmpmnjir.md) reads Nucleation as a test, not a proof.
