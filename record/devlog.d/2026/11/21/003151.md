**Wrong theories, in the order they were found out.**

1. **"Anchoring needs the error to be exactly zero" offered as new.** The
   assistant said it had missed this; the record already held it as
   [CLAIM-635](../../record/claims.d/CLAIM-635.md). Found by searching the record while writing the next answer.
   Lesson: search for the formal object before calling a result new.
2. **"Constraint does not make the transmitter less contractive."** Wrong:
   copying a feature exactly changes the step itself. Found by the owner's
   challenge (devlog entry of 00:31:49).
3. **"The variation within a level became sub-levels of a finer tree."**
   Read off a δ statistic without comparing tree topologies. Found by a
   direct check when the owner built on the sentence; corrected on the
   pull request before merge.
4. **"The time geometry is hyperbolic with δ bounded independently of the
   rates" offered as content.** True of every chain: the logarithm of any
   metric is nearly ultrametric. Found by the reader of Bovier and
   colleagues; checked by the assistant on 400 random metrics.
5. **"The record holds neither Freidlin–Wentzell nor metastability
   theory."** It holds both ([LIT-2035](../../record/literature.d/LIT-2035.md), [LIT-2037](../../record/literature.d/LIT-2037.md)). Found by the same reader's
   recheck. Lesson: "not held" needs a search for the field's terms, not
   only the title in hand.
6. **"Semicontraction is the general form of keeping a conserved part."**
   It contracts off a kernel and keeps nothing by itself. Found by the two
   semicontraction readers.

**A check that went red and was not looked at.** The first pull request of
the session (558) failed docs-check: a new argument's title contained a
code, which CI's link repair turned into a link in the heading, so title and
heading disagreed. The rule "titles carry no codes" was known and had been
applied to another title the same day. Five more pull requests were stacked
on it before anyone looked; the assistant read CI status only when the owner
asked for a retrospective. Fixed and merged forward through the stack on
2026-11-21. Filed as a postmortem.

branch to be deleted after filing; deleting the sixteen remote branches
returned HTTP 403. They are left for the owner.
