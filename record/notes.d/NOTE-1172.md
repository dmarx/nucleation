# NOTE-1172: Griffiths and Ghahramani — The Indian buffet process: an introduction and review

## Contribution

It gives the full derivation of a prior over sparse binary matrices with
finitely many rows and unboundedly many columns, by the same route that
takes a finite Dirichlet–multinomial mixture to the Chinese restaurant
process: write a finite model, pass to equivalence classes that forget
column labels, and take K → ∞. It shows the limit is generated by a simple
sequential process (the buffet), demonstrates it as the prior of an
infinite linear-Gaussian binary factor model, and surveys what the IBP had
been used for and generalised into by 2010.

## Key insight

A latent feature model needs a prior on *which objects have which
features* (Z) separately from *what the features are* (V or A), and the
effective dimension of the model is set by Z. If each feature's
prevalence is drawn as πk ~ Beta(α/K, 1), the expected number of
nonzero entries stays bounded as K grows, so the number of features can
be left unbounded while each object still holds finitely many. Feature
order is not identifiable, so the limit is taken over left-ordered
equivalence classes, not over matrices.

## Assumptions

- Objects (rows) exchangeable; features (columns) generated independently
  given their πk (§4.1, "the features are generated independently").
- Finite model (9): πk | α ~ Beta(α/K, 1), zik | πk ~ Bernoulli(πk). The
  choice s = 1 is relaxed only in §7.1.
- The limit is over lof-equivalence classes, appropriate "in models where
  feature order is not identifiable", such as any likelihood linear in F.
- The demonstration likelihood (§5): X = ZA + noise, A matrix-Gaussian,
  σX² I noise, so A can be integrated out.

## Key results

- **Finite model, (10)–(11).** P(Z) = ∏k (α/K)Γ(mk + α/K)Γ(N − mk + 1) /
  Γ(N + 1 + α/K), exchangeable in the rows. E[1ᵀzk] = N(α/K)/(1 + α/K),
  so E[1ᵀZ1] = Nα/(1 + α/K), "bounded above by Nα". Per object that is
  α/(1 + α/K) = Kα/(K + α).
- **The limit, (14).** P([Z]) → α^{K+} / ∏h Kh! · exp{−αH_N} ·
  ∏_{k≤K+} (N − mk)!(mk − 1)!/N!, with Appendix A taking the three limits
  term by term. H_N is the Nth harmonic number.
- **The buffet (§4.4).** Customer 1 takes Poisson(α) dishes; customer i
  takes each earlier dish with probability mk/i and then Poisson(α/i) new
  ones. Its matrices are not exchangeable, but their lof classes have the
  distribution (14). The "exchangeable IBP" samples by histories and is.
- **Properties (§4.6).** K+ ~ Poisson(αH_N); each object's feature count
  ~ Poisson(α); E[1ᵀZ1] = Nα, matching the finite model's limit.
- **Gibbs (§4.7).** Finite: P(zik = 1 | z−i,k) = (m−i,k + α/K)/(N + α/K)
  (17). Infinite: m−i,k/N for occupied columns (18), and Poisson(α/N) new
  columns. Footnote 5: the posterior version is "a heuristic strategy
  rather than a valid algorithm", because the order of updates depends on
  the state.
- **Linear-Gaussian model (§5).** The collapsed likelihood (21) for
  infinite Z is that of the finite model on its K+ occupied columns (26).
  On 100 6×6 images from four features the sampler finds four; on 100
  webcam photographs with up to four objects it settles on about seven
  features, four of which "perfectly indicate presence and absence of the
  four objects", while "Three less common features coded for slight
  differences in the locations of those objects". Of those four, three
  code the *absence* of an object (Fig. 9).
- **Extensions (§7).** Two-parameter IBP: Beta(αβ/K, β), mean features per
  object α, K+ ~ Poisson(α Σi β/(β + i − 1)). Stick-breaking (Teh et al.
  2007). Beta process as the de Finetti measure (Thibaux and Jordan,
  [LIT-1537](../literature.d/LIT-1537.md)), with a hierarchical version for several data sets.
  Column correlation via "a secondary process capturing patterns in the
  latent features" (Doshi-Velez and Ghahramani, [LIT-1544](../literature.d/LIT-1544.md)). Row
  dependence: the Markov IBP (Van Gael et al. 2009), whose rows follow a
  Markov process with two per-column parameters, "the probability of a 0
  in the previous row changing to a 1, and the probability of a 1 in the
  previous row remaining unchanged", and the phylogenetic IBP (Miller et
  al. 2008) on a tree.

## Concepts

- **lof-equivalence class [Z]**: binary matrices with the same
  left-ordered form, columns sorted by the binary number they spell, first
  row most significant. Plays the role a partition plays for class
  assignments.
- **History of feature k at object i**: (z1k, …, z(i−1)k); Kh counts the
  columns with full history h.
- **K+**: the number of columns with mk > 0, the model's effective
  dimension.
- **Exchangeable IBP**: the buffet variant that samples a Binomial number
  of each history's dishes and so produces left-ordered matrices directly.

## Bearing on the record

- **[CASE-165](../cases.d/CASE-165.md), item 1.** The paper supports the case's correction and
  shows where T23's quotation comes from. The αH_N count is stated only
  for the limit (§4.6); the finite model's only count is (11), whose
  per-object form Kα/(K + α) is the case's 2.53 at K = 16 and α = 3. The
  expected number of occupied features at finite K is not in the paper.
  It is K(1 − (α/K)B(α/K, N + 1)), strictly below αH_N for every finite
  K ([THEORY-999](../theory.d/THEORY-999.md)). At N = 12, α = 3 it is 6.83 at K = 16 against
  9.31, re-computed here. So T22's "generously truncated" is the paper's
  limit argument, and K = 16 is not generous by it.
- **[CASE-165](../cases.d/CASE-165.md), item 2.** The Markov IBP that §7.4 describes gives each
  feature its own 0→1 and 1→1 probabilities, so persistence is a
  per-feature parameter and not one ρ added to logit πk. The review
  describes it from Van Gael et al. (2009), which is not registered; it is
  the closest established relative of T23's sticky transition, closer than
  the dependent IBP, and the case could name it.
- **[CASE-165](../cases.d/CASE-165.md), items 3–4.** The paper says feature order is "not
  identifiable" and builds the prior on equivalence classes for that
  reason. Its own photograph demonstration shows two more freedoms. Three
  of its four main features code the absence of an object and one its
  presence (Fig. 9), so a 1 in a column need not mean "has"; the paper
  does not comment on it. And its seven features for four objects, three
  of them coding "slight differences in the locations", show a posterior
  adding features that refine an object, close to the split freedom item
  4 names.
- **[QUESTION-276](../questions.d/QUESTION-276.md).** The paper is the reference for the candidate
  method's prior. It supplies multiplicity and nothing more: the features
  are a posteriori whatever explains the data under a linear likelihood,
  which is [CLAIM-454](../claims.d/CLAIM-454.md)'s point that a recovered feature is at most a
  constituent.
- **[QUESTION-275](../questions.d/QUESTION-275.md).** §7.4's statement that exchangeability "is not
  warranted in cases where we have additional information about the
  properties of our observations" applies to T24's components, which the
  case already notes are not exchangeable.

No instruction for machine-learning practice; nothing for the anthology.

## Limitations

- **No finite-K count of occupied features.** The paper's finite model
  states only the bound on nonzero entries. A reader can take αH_N to
  hold for the truncated model it is not true of.
- **Exchangeable, independent columns.** The basic model has no dependence
  among features or over time; §7.4 lists the relaxations without
  deriving them.
- **The posterior sampler is heuristic** (footnote 5), and the number of
  new features is drawn by truncation "up to some reasonable upper bound"
  (§5.2).
- **Demonstrations, not evaluations.** The two §5.3 examples are single
  runs on data built to suit the model ("constructed in a way that removes
  many of the basic challenges of computer vision").
- **α couples sparsity and dimension** in the one-parameter model, which
  §7.1 calls "an undesirable constraint".
- **Survey sections** (§6, §7) describe other papers' results and were not
  checked against them.

## Open questions

- For a finite truncation, at what K is a given fraction of the limit's
  expected K+ reached, as a function of N and α? The formula above
  answers it numerically; the paper does not raise it.
- Which relaxation of exchangeability fits members of an organization or
  components of a network, whose rows are neither exchangeable nor
  ordered in time?

§7.4's description, two per-column parameters for a 0 turning to 1 and a
1 staying 1, is confirmed against the primary source: a ~ Beta(α/M, 1)
and b ~ Beta(γ, δ), drawn independently ([THEORY-1034](../theory.d/THEORY-1034.md)). The judgement

written on [CASE-165](../cases.d/CASE-165.md). The reading is unchanged.
