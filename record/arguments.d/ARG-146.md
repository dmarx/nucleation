# ARG-146: Dambre's equality → no memory–noise trade

## The inference

Theorem 7: a system with fading memory and N linearly independent observed
variables, driven by i.i.d. inputs, has capacities summing to N over a
complete basis of functions of all its inputs. Noise is a further input:
"It is only over the full space that Theorem 7 holds and that the
capacities will sum to N. However since v is unknown, the capacities which
are measurable are those which depend only on u … these capacities will
not sum to N."

## Critical questions (formal application)

**Does the mapping premise hold?** x(t) = Σ_j a^j(u(t−1−j) + η(t−1−j))
lies in the span of the degree-one functions u(t−1−k) and η(t−1−k), so its
capacities for higher-order functions are zero and the degree-one ones
are a^(2k)(1 − a²)·s²/(s² + σ²) for u and the same with σ² in the
numerator for η. Their total is 1 = N. The u-part is the claim's
s²/(s² + σ²).

**Are the model's assumptions met?** For |a| < 1: the state forgets its
initial condition geometrically, so the system has fading memory; N = 1 and
Var x > 0, so the rank condition holds; u and η are independent and i.i.d.
with finite fourth moments if Gaussian, and the paper names Hermite bases
for Gaussian input. The paper's capacity has no bias term; with zero-mean
inputs that changes nothing (its supplement §2 gives the centred variant).
At a = 1 fading memory fails, which is where the claim stops. With
σ² = s² the u-share is ½, the paper's "for a strictly linear system … the
capacity for a single input should equal N/K" with K = 2 (Fig. 4).

## Verdict

The claim's derivation is an instance of Theorem 7, not only of the bound,
and its independence of a is the theorem's, since the conditions hold at
every |a| < 1. [THEORY-2158](../theory.d/THEORY-2158.md) replaces [LIT-2971](../literature.d/LIT-2971.md) in the claim's
grounds. The readout-noise formula s²/(s² + σ² + ρ(1 − a²)) is not in the
paper; it is consistent with it if ν is a third input entering only the
observation. Nothing in the paper bears on the lag optimum a² = k/(k + 1).
