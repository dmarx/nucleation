summary: >-
  Reiter (1987), A theory of diagnosis from first principles. Reiter gives a
  logical theory of diagnosis that needs only a description of how a system
  behaves when its components work (SD), a set of components, and an
  observation (OBS) inconsistent with SD under the assumption that nothing
  is abnormal. A diagnosis is a minimal set of components whose abnormality,
  together with the normality of all the others, is consistent with SD and
  OBS. Diagnoses are characterized as the minimal hitting sets of the
  collection of conflict sets (de Kleer's concept), which yields an
  algorithm (DIAGNOSE, via a pruned HS-tree) for computing all diagnoses
  given a sound and complete theorem prover for the logic. Section 5 proves
  what a new measurement does to the set of diagnoses; Section 6 shows the
  theory holds for any binary-valued logic with the usual connectives and
  that diagnoses correspond one-to-one with the extensions of a default
  theory, so diagnostic reasoning is nonmonotonic. Read for the exchange
  "luria experiment design".
