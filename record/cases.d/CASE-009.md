# CASE-009: Text → image → caption → image chains under four conditions

## The case

A97 §6: "We could compare four conditions: text-only reconstruction, image-only
reconstruction, alternating text–image reconstruction, and alternating
reconstruction with explicit preservation of pragmatic constraints." A102's
fictional chain gives the shape of a run: comic ballad → modern aphorism → diner
image → caption as financial admonition → adviser/client scene.

## What it can show

If run, it bears on [QUESTION-012](../questions.d/QUESTION-012.md) and [CLAIM-087](../claims.d/CLAIM-087.md). Manuscript §10 Case III: "alternate
text→image→caption→image and compare against text-only reconstruction chains."
The image-only and explicit-constraint conditions were dropped without comment;
the second was the one that would test whether stating the relation stops the
drift.

C7 Appendix D adds the control the affordance argument ([CLAIM-076](../claims.d/CLAIM-076.md)) implies:
"For cross-modal chains, do not let captioners see the source text or the
intended communicative condition unless testing a specified side-information
intervention."
