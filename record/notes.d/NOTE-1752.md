# NOTE-1752: Yu, Kim and Kim (2026) — Retrieval Collapses When AI Pollutes the Web

## Contribution

A named failure mode for retrieval (as distinct from training-time model collapse), with descriptive metrics PCR / ECR / CCR, and a small controlled simulation showing exposure amplification of synthetic content and the decoupling of answer accuracy from source diversity.

## Key results

1. Abstract: "In the SEO scenario, a 67% pool contamination led to over 80% exposure contamination, creating a homogenized yet deceptively healthy state where answer accuracy remains stable despite the reliance on synthetic sources."
2. §4.2, Table 1a: BM25 ECR 0.4291 / 0.6809 / 0.8095 at PCR 0.33 / 0.50 / 0.67; LLM ranker 0.4508 / 0.7602 / 0.7998; AA BM25 0.6817 → 0.6768, LLM 0.6841 → 0.7023.
3. §4.2: "the system performs well in aggregate metrics while quietly losing its grounding in human-written content."
4. §3.1, pool quality: the Original Pool has "a Micro Correct Rate of 51.69%"; "The SEO Pool exhibits a Micro Correct Rate of 66.79%"; the Abuse Pool 38.44%.
5. §4.3: BM25 "allows approximately 19–24% of abusing documents to infiltrate the top-10 results"; the LLM ranker keeps ECR "near zero" (Table 1b: ≤ 0.0009).
6. §5, Limitations: "our metrics (PCR, ECR, CCR) are descriptive decompositions intended to characterize dynamics rather than novel theoretical measures."

## Assumptions

- "Web" = a fixed per-query pool of 10 real + up to 20 synthetic documents; contamination is added, never replaces originals.
- Synthetic SEO documents are generated from the original pool only; nothing generated by the answerer re-enters the pool, so no recursive loop is simulated.
- Correctness judged by an LLM (GPT-5-mini) against MS MARCO answers.
- Apparently single runs; no variance or significance reported.

## Concepts

Retrieval Collapse; Dominance and Homogenization (stage 1); Pollution and System Corruption (stage 2); Pool / Exposure / Citation Contamination Rate (PCR, ECR, CCR); "deceptively healthy state"; Defensive Ranking; ingestion-stage provenance filters.

## Bearing on the record

**On the LIT's and the exchange's characterization.** The numbers are right (67% → over 80%), but "simulates retrieval over a web increasingly polluted" overstates the setting: it is 1,000 queries with 30-document pools each, not a web crawl, and nothing feeds back. Two facts the summary omits change its reading: (a) the SEO synthetic documents are **more** often correct than the originals (66.79% vs 51.69%), so stage 1 is a loss of provenance and diversity, not of accuracy; (b) the adversarial stage is mostly filtered by the LLM ranker. The paper's "self-reinforcing cycle of quality decline" is a warning, not something it simulated. Minor internal inconsistency: §4.2 says the LLM ranker's ECR stays "consistently higher than that of BM25", but Table 1a has LLM 0.7998 < BM25 0.8095 at round 20.

- **[LIT-971](../literature.d/LIT-971.md)** (Gerstgrasser et al., accumulation bounds model collapse): *qualifies* the comparison the exchange draws. Both studies accumulate rather than replace (the original ten documents stay in every pool), yet here exposure is dominated by synthetic content anyway, because ranking amplifies it (ECR > PCR). Keeping the real data in the pool does not keep it in front of the user or the model. That is a distinct quantity from [LIT-971](../literature.d/LIT-971.md)'s test error, so it does not contradict [THEORY-289](../theory.d/THEORY-289.md); it shows that "the source sample stays in the pool" is not sufficient when a selection step sits between pool and consumer. *Leaves open* any recursive dynamics: there is no generation-from-retrieval loop here, so it says nothing about whether degradation compounds across rounds as in [LIT-971](../literature.d/LIT-971.md)'s chain.

## Limitations

Four-page short paper; one dataset, small pools, LLM-as-judge, GPT-5-nano for generation, ranking and answering (self-preference between same-family models is possible and only partly addressed by using GPT-5-mini as judge); no repeated runs; no live-web validation (the authors say so); "collapse" is a strong name for a result in which accuracy does not fall in stage 1.
