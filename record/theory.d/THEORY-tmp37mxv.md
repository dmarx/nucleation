# THEORY-tmp37mxv: Liu and Yadav (2026) describe STATE-Bench as 450 multi-turn enterprise tasks in which an agent changes a database through tools while a rule-bound simulated customer reveals information on request

## The account

Liu and Yadav (2026) describe STATE-Bench as 450 multi-turn enterprise tasks in which an agent changes a database through tools while a rule-bound simulated customer reveals information on request. State-changing tasks are scored by deterministic assertions on the final state, and reliability is the share of tasks passed in all five runs. They report that a GPT-5.1 agent without memory completes fewer than half the tasks reliably, about 30% in travel.
