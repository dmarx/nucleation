summary: >-
  Johan de Kleer and Brian C. Williams (1989), Proceedings of IJCAI-89, vol.
  2, pp. 1324–1330. Model-based diagnosis that uses only correct-behaviour
  models identifies faulty components without knowing how they fail, but
  treats unlikely faults as seriously as likely ones. Sherlock extends GDE
  so that each component has a set of behavioural modes (good modes, known
  fault modes, and an "unknown" mode that predicts nothing and so never
  conflicts with evidence), with prior probabilities. Diagnosis becomes
  identifying the most probable mode assignment. Like GDE, it represents
  mode literals as ATMS assumptions, computes minimal conflicts (nogoods),
  treats a candidate as a diagnosis iff it contains no minimal conflict,
  updates candidate probabilities by Bayes' rule after each measurement, and
  chooses the next measurement (and test vector) that minimizes expected
  entropy over the partitions the diagnostic objective cares about.
