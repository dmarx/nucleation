# QUESTION-tmpqba7g: What kind of game is search engine optimization, and has it a stable point, or is its arms race permanent?

## The players

- **The engine** commits to a ranking. It is meant to put first what users
  would find most relevant and best, and it can only read features that
  accompany those qualities.
- **Publishers** choose how to split effort between making better pages and
  manufacturing the features the ranking reads.
- **Users** give attention by rank, and so pay for both choices.

## The parts

1. What the ranking is, in the record's terms: a shortcut, a proxy, a signal?
2. Whether the engine's retraining against publishers' response can converge.
3. How authority-by-links (PageRank) is gamed, and what the record's account
   of authority says stops it.
4. What changes when the reader is a language model and not a ranked list.
