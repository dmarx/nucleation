# LIT-2235: Temporal Type Theory: A topos-theoretic approach to systems and behavior

## Key takeaways

Skimmed on 2026-11-22 ([NOTE-tmp43jkl](../notes.d/NOTE-tmp43jkl.md)). A coherent behavior type need not be any ODE's solution set; compliance on short windows need not compose; contracts compose by eliminating latent variables.
